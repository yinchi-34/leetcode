## 2. 题意理解（Problem Understanding）

题意、示例与约束见[排序解法](../sorting/summary.zh-CN.md#2-题意理解problem-understanding)。由那里的引理 1、2，答案为 $`\sum_i \lvert a_i - b_m \rvert`$，其中 $`b_m`$ 是升序排列后下标 $`m = \lfloor n/2 \rfloor`$ 的元素。

所以本题的核心子问题是：**给定数组和下标 $`k`$，求升序排列后位于下标 $`k`$ 的元素**，即第 $`k+1`$ 个顺序统计量。

## 3. 初始思路（Initial Approach）

### 第一次想到：随机快速选择（两路划分）

最初的 Go 版本用 CLRS 的 Lomuto 划分加随机主元做快速选择，见[两路划分快速选择](../lomuto-quickselect/summary.zh-CN.md)。

### 遇到的问题

讨论快速选择时有三个问题：

1. **为什么只递归一侧**：答对了，只需要第 $`k`$ 小的那一个位置。
2. **时间复杂度**：回答是 $`n^2`$。这是最坏情况，期望情况是 $`O(n)`$。
3. **Lomuto 是什么**：不知道这个名字，其实就是自己写的 `partition`。

把原来的代码在 $`n = 10^5`$ 上实测：随机数组约 36 万次比较、1 ms；**全相等数组约 37 亿次比较、7.7 秒**。

### 思维转变

从：

> 随机选主元就能避免最坏情况。

转变为：

> 随机化只能避免“运气差”。重复元素会让每个主元都变成最坏的主元，必须把等于主元的元素单独分成一段。

Lomuto 划分把所有等于主元的数放到左边，主元落在这一堆的最右端；数组全相等时，每一轮只排除 1 个元素。随机选中哪一个都一样，因为它们的值相同。改成三路划分（小于、等于、大于）后，一轮就排除整段相等的数；第 $`k`$ 小落在等于区时直接返回。同一个全相等数组降到约 0.26 ms。

## 4. 算法表达（Algorithm Specification）

**算法名称：** 三路划分随机快速选择（Randomized Quickselect with Three-Way Partitioning）

### 4.1 输入（Input）

$`A = \langle a_0, a_1, \ldots, a_{n-1} \rangle`$

满足：

- $`1 \le n \le 10^5`$
- $`a_i \in \mathbb{Z}`$，$`-10^9 \le a_i \le 10^9`$

### 4.2 输出（Output）

```math
\mathrm{res} = \sum_{i=0}^{n-1} \lvert a_i - b_m \rvert, \qquad m = \lfloor n/2 \rfloor .
```

### 4.3 伪代码（Pseudocode）

下标从 0 开始。

```text
PARTITION-3(A, l, r)                 // 主元 x = A[r]
    x ← A[r]
    lt ← l;  i ← l;  gt ← r
    while i ≤ gt
        if A[i] < x
            swap A[lt], A[i];  lt ← lt + 1;  i ← i + 1
        else if A[i] > x
            swap A[i], A[gt];  gt ← gt - 1    // i 不动：换来的 A[i] 还没看过
        else
            i ← i + 1
    return (lt, gt)                  // A[l..lt-1] < x，A[lt..gt] = x，A[gt+1..r] > x

QUICK-SELECT(A, l, r, k)             // 要求 l ≤ k ≤ r
    p ← 均匀随机取自 [l, r]
    swap A[p], A[r]
    (lt, gt) ← PARTITION-3(A, l, r)
    if k < lt
        return QUICK-SELECT(A, l, lt - 1, k)
    if k > gt
        return QUICK-SELECT(A, gt + 1, r, k)
    return A[k]

MIN-MOVES-2(A)
    x ← QUICK-SELECT(A, 0, n - 1, ⌊n/2⌋)
    res ← 0
    for i ← 0 to n - 1
        res ← res + |A[i] - x|
    return res
```

**状态定义**

- `lt`：等于区的左端，$`A[l..lt-1]`$ 都小于主元。
- `i`：下一个待检查的位置，$`A[lt..i-1]`$ 都等于主元。
- `gt`：未检查区的右端，$`A[gt+1..r]`$ 都大于主元。

### 4.4 正确性（Correctness）

**证明方法：三路划分用循环不变式；快速选择对子数组长度做强归纳。**

#### 一、正确性依赖的关键条件

1. **引理 1、2**（见[排序解法](../sorting/summary.zh-CN.md#44-正确性correctness)）：答案为 $`f(b_m) = \sum_i \lvert a_i - b_m \rvert`$。
2. **引理 3（三路划分）**：`PARTITION-3` 结束时，$`A[l..r]`$ 是原区间的一个排列，且满足返回值注释中的三段性质。
3. **引理 4（快速选择）**：`QUICK-SELECT(A, l, r, k)` 返回升序排列后位于下标 $`k`$ 的元素。

#### 二、正确性证明

**引理 3：三路划分的循环不变式**

在 `while` 循环每次检查条件时：

**不变式 I：四个区域**

- $`A[l..lt-1]`$ 中的元素都小于 $`x`$；
- $`A[lt..i-1]`$ 中的元素都等于 $`x`$；
- $`A[i..gt]`$ 尚未检查；
- $`A[gt+1..r]`$ 中的元素都大于 $`x`$。

**不变式 II：排列**

$`A[l..r]`$ 始终是原区间元素的一个排列。

**初始化**：$`lt = i = l`$，$`gt = r`$。前两个区域与最后一个区域为空，整个区间未检查；尚未交换。不变式成立。

**保持**：设本次检查前不变式成立，且 $`i \le gt`$。

- **$`A[i] < x`$**：交换 $`A[lt]`$ 与 $`A[i]`$。若 $`lt < i`$，换到位置 $`i`$ 的是等于区的第一个元素，等于 $`x`$；若 $`lt = i`$，这是自交换。两种情况下，$`lt`$、$`i`$ 各加 1 后，小于区多了一个小于 $`x`$ 的元素，等于区整体右移一格。
- **$`A[i] > x`$**：交换 $`A[i]`$ 与 $`A[gt]`$，$`gt`$ 减 1。原 $`A[i]`$ 进入大于区；换到位置 $`i`$ 的元素来自未检查区，仍未检查，所以 $`i`$ 不动。
- **$`A[i] = x`$**：等于区的右端就是 $`i`$，$`i`$ 加 1 即把它并入等于区。

每种情况只做交换，不变式 II 保持；不变式 I 也保持。

**终止**：每次迭代 $`i`$ 加 1 或 $`gt`$ 减 1，未检查区长度 $`gt - i + 1`$ 严格减小，所以循环终止，终止时 $`i = gt + 1`$，未检查区为空，四个区域变为三段。主元本身等于 $`x`$，所以等于区非空：$`lt \le gt`$。$`\square`$

**引理 4：快速选择**

把“$`A[l..r]`$ 的选择问题”定义为：这些元素在整个数组升序排列后恰好占据下标 $`l..r`$。主调用中 $`l = 0`$、$`r = n - 1`$，显然满足。

对区间长度 $`r - l + 1`$ 做强归纳。设 $`l \le k \le r`$。由引理 3，划分后小于区、等于区、大于区的元素在升序排列中依次占据下标 $`l..lt-1`$、$`lt..gt`$、$`gt+1..r`$。

- **$`k < lt`$**：下标 $`k`$ 处的元素在小于区，子区间 $`[l, lt-1]`$ 仍满足选择问题的前提，且 $`l \le k \le lt - 1`$。由于等于区非空，子区间严格更短，由归纳假设返回正确结果。
- **$`k > gt`$**：对称。
- **$`lt \le k \le gt`$**：下标 $`k`$ 处的元素等于 $`x`$，而 $`A[k] = x`$，直接返回。

长度为 1 时 $`lt = gt = l = k`$，落在第三种情况。所以 `QUICK-SELECT(A, 0, n-1, m)` 返回 $`b_m`$。$`\square`$

#### 三、结论

由引理 4，`QUICK-SELECT` 返回 $`b_m`$。随后对重排后的数组求和；重排不改变多重集合（引理 3），所以和等于 $`f(b_m)`$，由引理 1、2 即为答案。

### 4.5 复杂度分析（Complexity Analysis）

设输入规模为 $`n`$。`PARTITION-3` 处理长度为 $`s`$ 的区间要做 $`\Theta(s)`$ 次比较。

**时间复杂度：期望 O(n)，最坏 O(n²)**

**期望 $`O(n)`$（分阶段论证）**：给长度为 $`s`$ 的当前区间里的元素定一个全序：按值比较，值相同时按下标比较。随机主元在这个全序中的名次 $`\rho`$ 均匀分布在 $`0..s-1`$。小于区的元素名次都小于 $`\rho`$，大于区的都大于 $`\rho`$，所以下一层区间长度不超过 $`\max(\rho, s - 1 - \rho)`$。

$`\rho`$ 落在 $`[\lfloor s/4 \rfloor, \lceil 3s/4 \rceil)`$ 的概率至少 $`1/2`$，此时下一层长度不超过 $`3s/4`$。

把“当前长度在 $`(n(3/4)^{j+1}, n(3/4)^j]`$”称为第 $`j`$ 阶段。每次划分至少以 $`1/2`$ 的概率结束当前阶段，所以每个阶段的期望划分次数不超过 2，每次的代价不超过 $`c \cdot n (3/4)^j`$。于是

```math
\mathbb{E}[T(n)] \le \sum_{j \ge 0} 2c\,n\left(\tfrac{3}{4}\right)^{j} = 8c\,n = O(n) .
```

三路划分只会让下一层更短，所以重复元素不影响这个上界。求和一次遍历 $`\Theta(n)`$。

**最坏 $`O(n^2)`$**：若每次主元都是当前区间唯一的最小值或最大值，长度每次只减 1，总比较次数约 $`n^2/2`$。随机化使这种情况的概率极小，但不能排除。CLRS §9.3 的 SELECT（中位数的中位数）可以保证最坏 $`O(n)`$，本实现没有采用。

**空间复杂度：O(1)（不计递归栈）**

原地重排。递归深度期望 $`O(\log n)`$，最坏 $`O(n)`$。

## 5. 思维难点（Learning Notes）

### 难点一：随机选主元为什么挡不住重复元素

**理解过程**

随机化的期望分析要求主元的名次均匀分布。Lomuto 划分把等于主元的数全部归到左边，等于把每个相同的值都当成“最大的那个”。全相等时，无论选中哪一个，名次都是最后一名。三路划分把等于主元的整段一次排除，并且第 $`k`$ 小落在这一段时直接返回。

**可迁移思维：** 随机化解决的是“输入顺序或运气”带来的最坏情况，解决不了“值相同”带来的结构问题；分析随机算法时要检查期望论证依赖的假设，例如元素互不相同。

### 难点二：三路划分里 `i` 什么时候前进

**理解过程**

看 $`A[i]`$ 应该去哪个区：等于区就在 $`i`$ 左边，所以等于时只需 $`i`$ 加 1；小于时与等于区第一个元素交换，换回来的已知等于 $`x`$（或是自交换），所以 $`i`$ 可以前进；大于时与 $`A[gt]`$ 交换，换回来的还没检查过，所以 $`i`$ 不能前进。

**可迁移思维：** 写原地划分时，先画出各个区域及其边界指针，每个分支只问一句：“换到当前位置的元素是否已经检查过？”

## 6. 可迁移知识（Key Takeaways）

本题总结出以下可复用的方法：

1. **Quickselect（快速选择）**：本题用它在期望 $`O(n)`$ 内求第 $`\lfloor n/2 \rfloor`$ 小。适用于只需要一个顺序统计量、不需要完整排序的问题，如第 $`k`$ 大、前 $`k`$ 小。限制：最坏 $`O(n^2)`$，会原地打乱数组。
2. **Three-Way Partitioning（三路划分）**：本题用它避免重复元素导致的退化。适用于快速排序、快速选择中存在大量重复值的情况，也可以单独用来做“按与某值的大小关系分成三类”的原地整理。
