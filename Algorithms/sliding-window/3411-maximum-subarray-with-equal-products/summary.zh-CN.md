## 2. 题意理解（Problem Understanding）

给定正整数数组 `nums`。若子数组 `arr` 满足

```math
\mathrm{prod}(\mathrm{arr}) = \mathrm{lcm}(\mathrm{arr}) \cdot \gcd(\mathrm{arr})
```

则称它是**乘积等价**的，其中 $`\mathrm{prod}`$ 是所有元素之积，$`\gcd`$ 与 $`\mathrm{lcm}`$ 分别是所有元素的最大公约数与最小公倍数。求最长乘积等价子数组的长度。子数组指连续的非空片段。

**示例**

- 输入：`nums = [1,2,1,2,1,1,1]`
- 输出：`5`（子数组 `[1,2,1,1,1]`：乘积 2，$`\gcd = 1`$，$`\mathrm{lcm} = 2`$）

- 输入：`nums = [2,3,4,5,6]`
- 输出：`3`（子数组 `[3,4,5]`：乘积 60，$`\gcd = 1`$，$`\mathrm{lcm} = 60`$）

**关键要求**

1. $`2 \le n \le 100`$，$`1 \le \mathrm{nums}[i] \le 10`$。
2. 条件是关于整个子数组的整体等式，不能逐对相邻元素判断，需要先找到等价的结构性刻画。
3. 长度为 1 的子数组 $`[x]`$ 满足条件当且仅当 $`x = x^2`$，即 $`x = 1`$；由于 $`n \ge 2`$，它永远不会是唯一的最优解。

## 4. 算法表达（Algorithm Specification）

**算法名称：** 两两互质滑动窗口（Pairwise-Coprime Sliding Window）

### 4.1 输入（Input）

$`A = \langle a_0, a_1, \ldots, a_{n-1} \rangle`$

满足：

- $`2 \le n \le 100`$
- $`1 \le a_i \le 10`$

记 $`A[l..r] = \langle a_l, \ldots, a_r \rangle`$（$`0 \le l \le r < n`$），$`P(l, r) = \prod_{i=l}^{r} a_i`$；约定空乘积 $`P(l, l-1) = 1`$。

### 4.2 输出（Output）

```math
\mathrm{res} = \max\bigl\{\, r - l + 1 \;:\; 0 \le l \le r < n,\ \mathrm{prod}(A[l..r]) = \mathrm{lcm}(A[l..r]) \cdot \gcd(A[l..r]) \,\bigr\}
```

### 4.3 伪代码（Pseudocode）

下标从 0 开始。

```text
MAX-LENGTH(A)
    res ← 2                              // 任意长度为 2 的子数组都满足条件（引理 1）
    prod ← 1                             // prod = P(left, r-1)
    left ← 0
    for r ← 0 to n - 1
        while GCD(prod, A[r]) > 1        // A[r] 与窗口中某个元素不互质
            prod ← prod / A[left]
            left ← left + 1
        prod ← prod · A[r]
        res ← max(res, r - left + 1)
    return res

GCD(a, b)
    while b ≠ 0
        (a, b) ← (b, a mod b)
    return a
```

**状态定义**

- `left`、`r`：当前窗口为 $`A[\mathrm{left}..r]`$，代码中右端点叫 `right`。
- `prod`：当前窗口所有元素的乘积。
- `res`：目前找到的最长乘积等价子数组长度。

### 4.4 正确性（Correctness）

**证明方法：质因数指数比较 + 循环不变式**

#### 一、正确性依赖的关键条件

1. **算术基本定理**（题目之外的已知定理）：每个正整数都能唯一地写成质数幂之积；两个正整数相等，当且仅当每个质数在两边的指数都相等。
2. **长度 2 恒成立**（引理 1）：保证答案至少是 2，`res` 可以从 2 开始。
3. **长度至少为 3 时等价于两两互质**（引理 2）：把整体等式化成逐对的互质关系。
4. **两两互质对子数组封闭**：两两互质数组的任何子数组仍然两两互质，所以“以 $`r`$ 结尾的两两互质子数组”的左端点构成一个后缀区间，最小的左端点随 $`r`$ 单调不减，可以用滑动窗口维护。

#### 二、正确性证明

对正整数 $`m`$ 和质数 $`p`$，记 $`v_p(m)`$ 为 $`p`$ 在 $`m`$ 的质因数分解中的指数（不整除时为 0）。

**引理 1（两个数）**：对任意正整数 $`a, b`$，$`\gcd(a,b) \cdot \mathrm{lcm}(a,b) = a \cdot b`$。

*证明*：

第一步，写成质因数分解。设 $`a = \prod_p p^{x_p}`$，$`b = \prod_p p^{y_p}`$，其中 $`p`$ 跑遍所有质数，指数可以是 0。

第二步，写出 $`\gcd`$ 和 $`\mathrm{lcm}`$。按照定义：

```math
\gcd(a,b) = \prod_p p^{\min(x_p, y_p)}, \qquad \mathrm{lcm}(a,b) = \prod_p p^{\max(x_p, y_p)}
```

第三步，把两者相乘。同底数相乘，指数相加：

```math
\gcd(a,b) \cdot \mathrm{lcm}(a,b) = \prod_p p^{\min(x_p,y_p) + \max(x_p,y_p)}
```

第四步，用一个恒等式。对任意两个实数都有 $`\min(x,y) + \max(x,y) = x + y`$。理由是：一个取小的、一个取大的，两个数各用了一次，只是交换了顺序。

结论：所以 $`\gcd(a,b) \cdot \mathrm{lcm}(a,b) = \prod_p p^{x_p + y_p} = a \cdot b`$。

于是任意长度为 2 的子数组都是乘积等价的。由于 $`n \ge 2`$，这样的子数组一定存在，答案至少为 2。

**引理 2（三个及以上的数）**：设 $`k \ge 3`$，$`b_1, \ldots, b_k`$ 为正整数。则 $`\prod_i b_i = \mathrm{lcm}(b_1, \ldots, b_k) \cdot \gcd(b_1, \ldots, b_k)`$，当且仅当 $`b_1, \ldots, b_k`$ 两两互质。

*证明*：沿用引理 1 的四步。对每个质数 $`p`$，记 $`e_i = v_p(b_i)`$。乘积、$`\mathrm{lcm}`$、$`\gcd`$ 中 $`p`$ 的指数分别是 $`\sum_i e_i`$、$`\max_i e_i`$、$`\min_i e_i`$。由算术基本定理，等式成立当且仅当对每个质数 $`p`$ 都有

```math
\sum_{i=1}^{k} e_i = \max_i e_i + \min_i e_i
```

固定一个 $`p`$，把 $`e_1, \ldots, e_k`$ 从小到大排成 $`e_{(1)} \le e_{(2)} \le \cdots \le e_{(k)}`$。左边减去右边，得到中间 $`k-2`$ 项之和：

```math
\sum_{i=1}^{k} e_i - e_{(k)} - e_{(1)} = \sum_{j=2}^{k-1} e_{(j)}
```

所以上式等价于 $`\sum_{j=2}^{k-1} e_{(j)} = 0`$。

- **必要性**：若等式成立，中间各项非负且和为 0，所以全为 0。因为 $`k \ge 3`$，中间至少有一项 $`e_{(2)} = 0`$，于是 $`e_{(1)} \le e_{(2)} = 0`$。也就是说，$`e_1, \ldots, e_k`$ 中至多一个（即 $`e_{(k)}`$）为正：$`p`$ 至多整除一个 $`b_i`$。对所有质数都成立，就是两两互质。
- **充分性**：若两两互质，每个质数 $`p`$ 至多整除一个 $`b_i`$，所以 $`e_{(1)} = \cdots = e_{(k-1)} = 0`$，中间各项之和为 0，等式成立。

$`k = 2`$ 时中间没有项，等式无条件成立，这正是引理 1。$`k \ge 3`$ 的条件只在必要性中用到：它保证 $`\min`$ 被迫等于 0。

**推论（问题的等价形式）**：记 $`L^*`$ 为 $`A`$ 中最长两两互质子数组的长度（单个元素视为两两互质，所以 $`L^* \ge 1`$）。则答案等于 $`\max(2, L^*)`$。

*证明*：长度为 1 的乘积等价子数组长度为 1，长度为 2 的由引理 1 全部满足，长度至少为 3 的由引理 2 恰好是两两互质子数组。所以乘积等价子数组的最大长度是 $`\max(2, L^*)`$。

接下来只需证明算法算出 $`\max(2, L^*)`$。对每个 $`r`$，定义

```math
\ell(r) = \min\{\, l \le r : A[l..r] \text{ 两两互质} \,\}
```

由于 $`A[r..r]`$ 两两互质，这个集合非空。由两两互质对子数组封闭，$`A[l..r]`$ 两两互质当且仅当 $`\ell(r) \le l \le r`$；并且 $`\ell(r) \le \ell(r+1)`$，因为 $`A[\ell(r+1)..r+1]`$ 两两互质，去掉末尾后 $`A[\ell(r+1)..r]`$ 仍两两互质。

**循环不变式**

在第 $`r`$ 次外层迭代开始时（$`0 \le r \le n`$，$`r = n`$ 表示循环结束后）：

**不变式 I：窗口**

$`\mathrm{left} = \ell(r-1)`$（约定 $`\ell(-1) = 0`$），并且 $`\mathrm{prod} = P(\mathrm{left}, r-1)`$。

**不变式 II：结果**

$`\mathrm{res} = \max\bigl(2,\ \max_{0 \le j < r} (j - \ell(j) + 1)\bigr)`$。

**初始化（Initialization）**

$`r = 0`$ 时，$`\mathrm{left} = 0 = \ell(-1)`$，$`\mathrm{prod} = 1 = P(0, -1)`$；$`\mathrm{res} = 2`$，内层最大值取空集，不变式成立。

**保持（Maintenance）**

假设第 $`r`$ 次迭代开始时不变式成立，记 $`x = a_r`$。

*内层 `while` 循环*：它的不变式是“$`\mathrm{prod} = P(\mathrm{left}, r-1)`$，$`A[\mathrm{left}..r-1]`$ 两两互质，且 $`\mathrm{left} \le \ell(r)`$”。

- 开始时由不变式 I 成立；$`\ell(r-1) \le \ell(r)`$ 给出最后一条。
- 关键判定：当 $`A[\mathrm{left}..r-1]`$ 两两互质时，$`A[\mathrm{left}..r]`$ 两两互质当且仅当 $`\gcd(\mathrm{prod}, x) = 1`$。因为 $`\mathrm{prod}`$ 的质因子恰好是窗口中各元素质因子的并集，$`x`$ 与 $`\mathrm{prod}`$ 有公共质因子当且仅当 $`x`$ 与窗口中某个元素有公共质因子。
- 若 $`\gcd(\mathrm{prod}, x) > 1`$，则 $`A[\mathrm{left}..r]`$ 不两两互质，所以 $`\mathrm{left} < \ell(r)`$，将 $`\mathrm{left}`$ 加 1 后仍有 $`\mathrm{left} \le \ell(r)`$。$`\mathrm{prod}`$ 是 $`a_{\mathrm{left}}`$ 与其余元素之积，除法 `prod / A[left]` 是整除，结果为 $`P(\mathrm{left}+1, r-1)`$；子数组仍两两互质。
- 终止：窗口为空（$`\mathrm{left} = r`$）时 $`\mathrm{prod} = 1`$，$`\gcd(1, x) = 1`$，循环必然退出，所以 $`\mathrm{left} \le r`$，循环至多执行 $`r - \ell(r-1)`$ 次。退出时 $`\gcd(\mathrm{prod}, x) = 1`$，由关键判定，$`A[\mathrm{left}..r]`$ 两两互质，所以 $`\mathrm{left} \ge \ell(r)`$。结合 $`\mathrm{left} \le \ell(r)`$，得 $`\mathrm{left} = \ell(r)`$。

*循环体其余部分*：`prod ← prod · x` 后 $`\mathrm{prod} = P(\ell(r), r)`$，下一次迭代开始时不变式 I 成立。`res ← max(res, r - left + 1)` 把 $`r - \ell(r) + 1`$ 纳入最大值，不变式 II 成立。

**终止（Termination）**

外层循环执行 $`n`$ 次后结束。由不变式 II，

```math
\mathrm{res} = \max\Bigl(2,\ \max_{0 \le j < n} \bigl(j - \ell(j) + 1\bigr)\Bigr)
```

任何两两互质子数组 $`A[l..j]`$ 都满足 $`l \ge \ell(j)`$，长度不超过 $`j - \ell(j) + 1`$；而 $`A[\ell(j)..j]`$ 本身两两互质。所以内层最大值就是 $`L^*`$，$`\mathrm{res} = \max(2, L^*)`$，由推论即为答案。

**不会溢出**：窗口两两互质，每个质数至多出现在一个元素中，所以 $`v_p(\mathrm{prod})`$ 等于某个 $`a_i \le 10`$ 的 $`v_p(a_i)`$。1 到 10 中 2、3、5、7 的最高次幂分别为 $`2^3, 3^2, 5, 7`$，所以 $`\mathrm{prod}`$ 整除 $`2^3 \cdot 3^2 \cdot 5 \cdot 7 = 2520`$。乘上新元素之前 $`\mathrm{prod} \le 2520`$，乘之后不超过 $`25200`$，远在 Go `int` 的范围内。

#### 三、结论

引理 1 和引理 2 把“乘积等于最小公倍数乘最大公约数”化为“长度为 2，或两两互质”。两两互质对子数组封闭，所以以每个位置结尾的最长两两互质子数组可以用单调前进的左指针维护，而用窗口乘积与新元素做一次 $`\gcd`$ 就能判断新元素能否加入。算法对所有合法输入都返回 $`\max(2, L^*)`$，即最长乘积等价子数组的长度。

### 4.5 复杂度分析（Complexity Analysis）

设 $`n`$ 为数组长度，$`C = 25200`$ 为参与 $`\gcd`$ 运算的数的上界（见上节“不会溢出”）。

**时间复杂度：O(n log C)**

外层循环执行 $`n`$ 次。内层 `while` 每次成功执行都让 `left` 加 1，而 `left` 只增不减且不超过 $`n`$，所以用聚合分析，内层循环体在整个算法中至多执行 $`n`$ 次；每次外层迭代还有一次使条件为假的判断。合计 $`\gcd`$ 调用至多 $`2n`$ 次，每次欧几里得算法需要 $`O(\log C)`$ 步。总时间 $`O(n \log C)`$；在本题约束下 $`C`$ 是常数，也就是 $`O(n)`$。

**空间复杂度：O(1)**

只使用 `res`、`prod`、`left`、`right` 几个整数变量，不修改、不复制输入。

### 4.6 实现细节：Go 与 Python（Implementation Notes）

- **最大公约数**：Go 标准库没有整数版 $`\gcd`$，`solution.go` 自己写了欧几里得算法；Python 直接用 `math.gcd`。见[最大公约数](../../../docs/LANGUAGE_NOTES.zh-CN.md#最大公约数)。
- **整除**：Go 的 `prod /= nums[left]` 对正整数就是整除；Python 必须写 `prod //= nums[left]`，写成 `/=` 会把 `prod` 变成浮点数，之后 `math.gcd` 会因为参数不是整数而报错。见[负数的除法与取模](../../../docs/LANGUAGE_NOTES.zh-CN.md#负数的除法与取模)。
- **整数范围**：由“不会溢出”的论证，窗口乘积不超过 25200，Go 的 `int` 足够，两种语言没有差异。
- 其余逐行对应。

## 5. 思维难点（Learning Notes）

### 难点一：一个整体等式，怎样变成逐对的互质关系？

题目条件同时涉及乘积、最小公倍数和最大公约数三个整体量，直接看看不出子数组应当长什么样。

**理解过程**

三个量都是“对每个质数取指数的某种统计”：乘积取指数之和，最小公倍数取最大值，最大公约数取最小值。按质数拆开后，原来的整体等式变成彼此独立的若干个指数等式 $`\sum e_i = \max e_i + \min e_i`$。两个数时这是恒等式 $`\min + \max = x + y`$（引理 1）；三个及以上时，多出来的中间项必须全为 0，同时 $`\min`$ 被迫为 0，也就是每个质数只能出现在一个元素里（引理 2）。

**可迁移思维：** 看到 $`\gcd`$、$`\mathrm{lcm}`$、乘积、整除混在一起的条件时，先按质数拆成指数，把乘法关系变成加法、取最大、取最小的关系，再逐个质数分析。

### 难点二：为什么能用滑动窗口？

不是所有“最长子数组”问题都能用双指针。

**理解过程**

滑动窗口成立需要性质对子数组封闭：如果 $`A[l..r]`$ 满足性质，那么所有更短的 $`A[l'..r']`$（$`l \le l' \le r' \le r`$）也满足。两两互质满足这一点，因为去掉元素不会制造新的公共质因子。由此推出以 $`r`$ 结尾的合法左端点是一段后缀，最小合法左端点 $`\ell(r)`$ 随 $`r`$ 单调不减，左指针不需要回退。注意原始的“乘积等价”性质本身**不**对子数组封闭：`[2,3]` 满足，它的子数组 `[2]` 却不满足（$`2 \ne 2 \cdot 2`$）；`[2,4]` 满足，却不是两两互质，以它为窗口继续向右扩展只会得到不满足的数组。所以必须先做难点一的转换，再谈滑动窗口。

**可迁移思维：** 用滑动窗口前先检查性质是否对子数组封闭；原题条件不封闭时，看看能否先把它化成一个封闭的等价条件，剩下的特殊情况（这里是长度 2）单独处理。

### 难点三：怎样 O(1) 判断新元素能否加入窗口？

逐个检查新元素与窗口中每个元素是否互质需要 $`O(\text{窗口长度})`$。

**理解过程**

窗口两两互质时，窗口乘积的质因子就是各元素质因子的并集，所以“$`x`$ 与窗口中每个元素都互质”等价于 $`\gcd(\mathrm{prod}, x) = 1`$。移出左端元素时，由于它与其余元素互质，可以直接从乘积中整除掉。乘积还天然有界（整除 2520），不会溢出。

**可迁移思维：** 维护集合的“并”信息时，若能用一个可逆的聚合量（这里是乘积，逆运算是整除）表示，就能在滑动窗口中 $`O(1)`$ 地加入和移出元素。前提是逆运算合法：这里依赖窗口两两互质，整除才精确。

## 6. 可迁移知识（Key Takeaways）

本题总结出以下可复用的方法：

1. **Prime Exponent Decomposition（质因数指数分解）**：在本题中把 $`\mathrm{prod} = \mathrm{lcm} \cdot \gcd`$ 化成每个质数上的 $`\sum e_i = \max e_i + \min e_i`$。适用于条件由乘积、$`\gcd`$、$`\mathrm{lcm}`$、整除构成的问题；依赖算术基本定理，只对正整数成立。
2. **Sliding Window over a Hereditary Property（对子数组封闭性质的滑动窗口）**：在本题中维护以 $`r`$ 结尾的最长两两互质子数组。适用于“求满足某性质的最长或计数子数组”且性质对子数组封闭的问题；性质不封闭时窗口的单调性不成立。
3. **Invertible Window Aggregate（可逆的窗口聚合量）**：在本题中用窗口乘积 `prod` 和一次 $`\gcd`$ 判断新元素是否与整个窗口互质，移出时整除。适用于窗口信息能被一个支持“加入”和“撤销”的量概括的情形，类似前缀和；限制是逆运算必须精确（这里依赖两两互质保证整除）且聚合量不能溢出。
4. **Small-Case Separation（小规模情况单独处理）**：引理 2 只对长度至少为 3 成立，长度 2 由引理 1 单独给出，于是 `res` 从 2 开始。适用于一般结论在小规模下失效或退化的问题。
