## 3. 初始思路（Initial Approach）

### 第一次想到：反过来看

代码按 `sum - len(nums)*mn` 写出来了，但没有理解为什么可以“反过来看”：“其余 $`n-1`$ 个加 1”和“一个减 1”对相对差值没有区别，可为什么能凭这一点直接换成另一个问题？

### 遇到的问题

讨论中依次出现了几个疑问：

1. 这一行是怎么算的？为什么是 $`n`$ 个 $`\min`$？
2. 成批模拟已经把一批压缩成一次减法，公式又在哪里完成了压缩？
3. 反过来时，会不会把某个数减到比最小值还小，导致目标变了？
4. 正向时“该操作谁”一直在变，反向以后难道不变吗？反向的意义在哪？

### 思维转变

从：

> 反向是另一个过程，基准也会跟着变。

转变为：

> 反向是同一个过程换一个参照系：去掉每一步的整体上升后，每一步只动一个数，数与数之间互不影响，最小值也不动。

这些疑问的回答见第 5 节。

## 4. 算法表达（Algorithm Specification）

**算法名称：** 公式法（Closed-Form Formula）

### 4.1 输入（Input）

$`A = \langle a_0, a_1, \ldots, a_{n-1} \rangle`$

满足：

- $`1 \le n \le 10^5`$
- $`a_i \in \mathbb{Z}`$，$`-10^9 \le a_i \le 10^9`$

### 4.2 输出（Output）

最少操作次数 $`k^* = \sum_i a_i - n \cdot \min_i a_i`$。

### 4.3 伪代码（Pseudocode）

下标从 0 开始。

```text
MIN-MOVES(A)
    S ← 0
    μ ← A[0]
    for i ← 0 to n - 1
        S ← S + A[i]
        μ ← min(μ, A[i])
    return S - n · μ
```

**状态定义**

- `S`：已遍历元素之和。
- `μ`：已遍历元素的最小值。

### 4.4 正确性（Correctness）

**证明方法：等价变换（平移不变性 + 对步数归纳），再对等价问题证明下界与可达。**

**记号**：$`S = \sum_i a_i`$，$`\mu = \min_i a_i`$。$`\mathbf{1} = (1, \ldots, 1)`$，$`e_j`$ 是第 $`j`$ 位为 1、其余为 0 的向量。

#### 一、正确性依赖的关键条件

1. **引理 2（平移不变）**：对任意常数 $`t`$，$`x`$ 全部相等当且仅当 $`x + t\mathbf{1}`$ 全部相等。
2. **引理 3（问题等价）**：原问题与“每次让一个数减 1”的问题在同一步变成全部相等。

引理 2：$`x_i = x_j \iff x_i + t = x_j + t`$。

#### 二、正确性证明

**引理 3**：从 $`a`$ 出发，按同一串下标 $`j_0, j_1, \ldots`$ 操作，原问题第 $`t`$ 步跳过 $`j_t`$，新问题第 $`t`$ 步让 $`j_t`$ 减 1，第 $`t`$ 步后的状态分别为 $`x^{(t)}`$ 和 $`y^{(t)}`$。则

```math
x^{(t)} = y^{(t)} + t\,\mathbf{1} .
```

*证明*：对 $`t`$ 归纳。$`t = 0`$ 时两边都是 $`a`$。若对 $`t`$ 成立，因为跳过 $`j_t`$ 等于“全体加 1、再让 $`j_t`$ 减 1”，

```math
x^{(t+1)} = x^{(t)} + \mathbf{1} - e_{j_t} = \bigl(y^{(t)} - e_{j_t}\bigr) + (t+1)\mathbf{1} = y^{(t+1)} + (t+1)\mathbf{1} . \qquad \square
```

由引理 2，$`x^{(t)}`$ 全部相等当且仅当 $`y^{(t)}`$ 全部相等。两个问题的操作序列一一对应、步数相同，所以最少步数相同。注意两边的**最终值并不相同**：相同的是“在哪一步变成全部相等”。

**求解等价问题**：在新问题里，每个数只减不增。

- **下界**：若最终全部等于 $`T`$，则 $`T \le \mu`$，总步数 $`\sum_i (a_i - T) = S - nT \ge S - n\mu`$。
- **可达**：取 $`T = \mu`$，第 $`i`$ 个数减 $`a_i - \mu`$ 次，共 $`S - n\mu`$ 步。

所以 $`k^* = S - n\mu`$。

#### 三、结论

由引理 3，原问题的最少步数等于等价问题的最少步数 $`S - n\mu`$，算法一次遍历求出 $`S`$ 和 $`\mu`$ 后返回它。同一个值也可以由[成批模拟解法](../batched-simulation/summary.zh-CN.md#44-正确性correctness)的势函数下界独立得到。

### 4.5 复杂度分析（Complexity Analysis）

设输入规模为 $`n`$。

**时间复杂度：Θ(n)**

一次遍历，每个元素做一次加法和一次比较。

**空间复杂度：O(1)**

只用两个变量。

**数值范围**：$`\lvert S \rvert \le 10^5 \cdot 10^9 = 10^{14}`$，$`n \cdot \lvert\mu\rvert`$ 同样不超过 $`10^{14}`$，在 64 位 `int` 范围内。

## 5. 思维难点（Learning Notes）

### 难点一：为什么是 $`n`$ 个 $`\min`$，压缩又在哪里完成

**理解过程**

- **拆开求和**：$`\sum_{i=0}^{n-1} (a_i - \mu) = \sum a_i - \sum \mu`$。$`\mu`$ 不随 $`i`$ 变化，一共 $`n`$ 项，所以是 $`n\mu`$。最小值自己那一项是 $`\mu - \mu = 0`$，但仍算在 $`n`$ 项里。
- **两次压缩**：成批模拟把第 $`i`$ 批的 $`a_i - a_0`$ 步压成一次减法，这是第一次。每批长度只取决于 $`a_i`$ 和最小值，与其他批的顺序和步数无关，所以不必排序、不必按顺序追，直接把所有批加起来，这是第二次，就是 `sum - n*mn` 这一行。
- **画成柱状图**：每个数画成一根柱子，所有格子共 $`S`$ 个，最小值那一层以下是 $`n\mu`$ 个，以上的每一格对应一步。成批模拟按柱子逐根数这些格子，公式先数全部再减掉底下的矩形，数的是同一片格子。

**可迁移思维：** 若每批的长度互不依赖，批次的顺序就无关紧要，求和可以直接写成闭式。

### 难点二：反过来时，基准会不会变

**理解过程**

这里有两种“基准”：

- **终点**：反向时只减不增，减到最小值以下只会多走步（每低 1，$`n`$ 个数都要多减 1），所以最优方案不碰最小值，终点固定在 $`\mu`$。
- **下一步操作谁**：反向时如果规定“每次减最大值”，这个选择也会变。但反向每一步只动一个数，数与数之间互不影响，第 $`i`$ 个数固定需要 $`a_i - \mu`$ 次，顺序无关，所以根本不用选。

正向其实也是这样：只要第 $`i`$ 个数被跳过 $`a_i - \mu`$ 次，按任意顺序做最后都会相等（引理 1）。正向看不出来，是因为每一步都牵动 $`n-1`$ 个数。

**参照系**：反向就是站在一部每步上升 1 的电梯里看正向过程，$`y = x - t\mathbf{1}`$。最小值从不被跳过，每步恰好上升 1，所以在电梯里看它不动。以 `[1,2,3]` 为例：

| 第 $`t`$ 步 | 正向 $`x`$ | 反向 $`y = x - t\mathbf{1}`$ |
|---|---|---|
| 0 | `[1,2,3]` | `[1,2,3]` |
| 1（跳过第 3 个） | `[2,3,3]` | `[1,2,2]` |
| 2（跳过第 2 个） | `[3,3,4]` | `[1,1,2]` |
| 3（跳过第 3 个） | `[4,4,4]` | `[1,1,1]` |

**可迁移思维：** 反向不是新算法，而是一个视角：把“每步牵动 $`n-1`$ 个数”变成“每步只动一个数”，从而看出各元素互相独立。

## 6. 可迁移知识（Key Takeaways）

本题总结出以下可复用的方法：

1. **Translation Invariance（平移不变性）**：目标只依赖差值时，把操作分解为“整体平移 + 局部变化”，转化为等价问题。本题的“$`n-1`$ 个加 1”就等价于“1 个减 1”。限制：只能在目标确实与整体平移无关时使用；若题目要求最终值等于某个给定数，就不能丢掉平移。
2. **Closed Form from Independent Batches（独立批次求闭式）**：每批长度互不依赖时，跳过模拟直接求和。适用于能先证明“各部分的贡献与顺序无关”的计数问题。
