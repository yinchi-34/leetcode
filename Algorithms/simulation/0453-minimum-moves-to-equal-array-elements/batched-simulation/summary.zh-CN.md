## 2. 题意理解（Problem Understanding）

给定长度为 $`n`$ 的整数数组 `nums`。一次操作选择其中 $`n-1`$ 个元素，各加 1。求使所有元素相等的最少操作次数。

**示例**

- 输入：`nums = [1,2,3]`
- 输出：`3`（`[1,2,3] → [2,3,3] → [3,4,3] → [4,4,4]`）

**关键要求**

1. 输入约束：$`1 \le n \le 10^5`$，$`-10^9 \le a_i \le 10^9`$，答案保证在 32 位整数范围内。
2. 每次恰好有一个元素不加 1，下文称为“跳过”这个元素。题目不要求最终值等于某个给定的数。
3. 边界：$`n = 1`$ 或所有元素已经相等时，答案为 0。

## 3. 初始思路（Initial Approach）

### 第一次想到：反过来看

代码按“答案是 $`\sum a_i - n \cdot \min a`$”写出来了，测试也能通过，但没有理解为什么可以“反过来看”。有两个疑问：

1. 直接一步一步模拟为什么不行？题目并没有说不能这样走。
2. “其余 $`n-1`$ 个加 1”和“一个减 1”，对各元素之间的相对差值来说没有区别。可为什么能凭这一点直接换成另一个问题？

第 2 个疑问在[公式解法](../formula/summary.zh-CN.md)中讨论，本文回答第 1 个。

### 遇到的问题

逐步模拟本身是合法的，问题在于步数。以 `[1, 1000000000]` 为例，每一步最多让差距缩小 1，要走约 $`10^9`$ 步；$`n`$ 取到 $`10^5`$ 时，每一步还要 $`O(n)`$，总运算量可达 $`10^{14}`$ 量级。

所以真正的问题是：能不能**不走**这么多步，直接算出步数？

### 思维转变

从：

> 每一步该跳过谁？

转变为：

> 很多连续的步骤跳过的是同一个数，能不能把它们合并成一批，一次算出这一批的步数？

自己整理出的过程是：排序后，“已经相等的一组”去追下一个数。追的时候跳过被追的数，其他数都加 1；追平就停，被追的数并入组，组变大，再追下一个，直到全部相等。

在这个过程上需要修正两处：

- 每批的步数不是“当前最小值和全局最大值之差”，而是组的值和被追的数的**当前值**之差。被追的数在前几批里一直在加 1。
- 每批跳过的是被追的数，它通常不是全局最大值。所以基础的逐步模拟要写成“每步跳过任意一个非最小值”，而不是“每步跳过最大值”，成批模拟才是它的一种特例，两者才能共用同一个证明。

再往下推，就得到每批步数恰好是 $`a_i - a_0`$（第 5 节难点一）。

## 4. 算法表达（Algorithm Specification）

**算法名称：** 成批模拟（Batched Simulation）

### 4.1 输入（Input）

$`A = \langle a_0, a_1, \ldots, a_{n-1} \rangle`$

满足：

- $`1 \le n \le 10^5`$
- $`a_i \in \mathbb{Z}`$，$`-10^9 \le a_i \le 10^9`$

### 4.2 输出（Output）

最少操作次数 $`k^*`$：存在一个长度为 $`k^*`$ 的操作序列使所有元素相等，并且不存在更短的序列。

### 4.3 伪代码（Pseudocode）

下标从 0 开始。

```text
MIN-MOVES-BATCHED(A)
    B ← SORT(copy of A)              // 升序
    res ← 0
    for i ← 1 to n - 1
        cur ← B[i] + res             // B[i] 从未被跳过，已经加了 res 次
        res ← res + (cur - B[i-1])   // 前缀追平 B[i]，跳过 B[i] 共 cur - B[i-1] 次
        B[i] ← cur                   // 前缀现在都等于 cur
    return res
```

**状态定义**

- `res`：已经走过的总步数。
- `B[i-1]`：第 $`i`$ 批开始时，前缀 $`B[0..i-1]`$ 的共同值。

### 4.4 正确性（Correctness）

**证明方法：势函数给出下界；循环不变式证明成批模拟恰好达到下界。**

**记号**：$`S = \sum_i a_i`$，$`\mu = \min_i a_i`$。操作 $`\mathrm{op}_j`$ 表示除 $`j`$ 以外的元素各加 1，称为“跳过 $`j`$”。

**定理**：最少操作次数 $`k^* = S - n\mu`$。

#### 一、正确性依赖的关键条件

1. **引理 1（计数）**：做了 $`k`$ 次操作、下标 $`j`$ 被跳过 $`c_j`$ 次时，$`\sum_j c_j = k`$，且当前值 $`x_i = a_i + k - c_i`$。特别地，从未被跳过的元素都加了 $`k`$，彼此的差值保持原样。
2. **势函数**：$`\Phi(x) = \sum_i x_i - n \cdot \min x`$。$`\Phi(x) \ge 0`$，且 $`\Phi(x) = 0`$ 当且仅当全部相等。

引理 1：每次操作恰好跳过一个下标，所以 $`\sum_j c_j = k`$；元素 $`i`$ 只在被跳过的 $`c_i`$ 次里没有加 1。

#### 二、正确性证明

**（1）直接模拟：下界与可达**

考察任意一次操作对 $`\Phi`$ 的影响。总和增加 $`n-1`$；最小值最多增加 1，并且当跳过的不是最小值时，所有最小值元素都加了 1，最小值恰好增加 1。所以

```math
\Delta\Phi = (n-1) - n \cdot \Delta\min x \ \ge\ -1,
```

当跳过的不是最小值时取等号。

- **下界**：每一步最多让 $`\Phi`$ 减少 1，终点要求 $`\Phi = 0`$，所以任何方案至少需要 $`\Phi(a) = S - n\mu`$ 步。
- **可达**：只要还没有全部相等，就跳过一个非最小值，$`\Phi`$ 每步恰好减少 1，$`S - n\mu`$ 步后结束。

所以 $`k^* = S - n\mu`$。直接模拟的问题只在于步数太多。

**（2）成批模拟的循环不变式**

设 `B` 已升序排列，于是 $`B_0 = \mu`$。在 `for` 循环第 $`i`$ 次迭代开始时（$`1 \le i \le n`$，$`i = n`$ 表示循环结束），把整个过程看成在排序后的数组上实际执行操作：

**不变式 I：前缀相等**

已执行 `res` 步，前缀 $`0..i-1`$ 的当前值全部等于 `B[i-1]`。

**不变式 II：后缀从未被跳过**

下标 $`0`$ 和所有 $`j \ge i`$ 都从未被跳过；对 $`j \ge i`$，`B[j]` 仍是原值 $`B_j`$。

**初始化**：$`i = 1`$ 时 `res = 0`，前缀只有一个元素，没有任何下标被跳过，两条不变式成立。

**保持**：设第 $`i`$ 次迭代前不变式成立。由不变式 II 和引理 1，下标 $`i`$ 的当前值为 $`B_i + \mathrm{res}`$，也就是 `cur`。下标 $`0`$ 也从未被跳过，当前值为 $`B_0 + \mathrm{res}`$；由不变式 I，它等于 `B[i-1]`。所以本批步数

```math
d_i = \mathrm{cur} - B[i-1] = (B_i + \mathrm{res}) - (B_0 + \mathrm{res}) = B_i - B_0 \ge 0 .
```

$`d_i \ge 0`$ 来自排序，所以本批是良定义的。连续跳过下标 $`i`$ 共 $`d_i`$ 次：下标 $`i`$ 不动，前缀每步加 1，正好追平到 `cur`；$`j > i`$ 的元素也加了 $`d_i`$，但没有被跳过。代码执行 `res += d_i` 和 `B[i] = cur` 后，前缀 $`0..i`$ 全部等于 `B[i]`，且只有下标 $`i`$ 新被跳过过，不变式对 $`i+1`$ 成立。

**终止**：循环在 $`i = n`$ 时结束。由不变式 I，全部 $`n`$ 个元素相等，总步数

```math
\mathrm{res} = \sum_{i=1}^{n-1} (B_i - B_0) = S - n\mu .
```

每批跳过的下标 $`i`$ 在追平之前都严格大于前缀，所以每一步都是“跳过非最小值”，是（1）中可达方案的一种。

#### 三、结论

（1）对任意合法输入给出下界 $`S - n\mu`$，（2）证明成批模拟恰好走出一个达到下界的方案，所以算法返回 $`k^*`$。

### 4.5 复杂度分析（Complexity Analysis）

设输入规模为 $`n`$。

**时间复杂度：O(n log n)**

排序 $`O(n \log n)`$，之后一次遍历 $`\Theta(n)`$。

**空间复杂度：O(n)**

复制数组再排序，额外空间 $`\Theta(n)`$。若允许修改输入，可以原地排序，额外空间取决于 `sort.Ints` 的实现（Go 的 pdqsort 为 $`O(\log n)`$ 栈空间）。

**数值范围**：$`\lvert S \rvert \le 10^5 \cdot 10^9 = 10^{14}`$，$`n \cdot \lvert\mu\rvert`$ 同样不超过 $`10^{14}`$，在 64 位 `int` 范围内。

## 5. 思维难点（Learning Notes）

### 难点一：每批步数为什么恰好是 $`a_i - a_0`$

用字母推第 2 批时，$`d_2 = (a_2 + d_1) - a_1`$，代入 $`d_1 = a_1 - a_0`$ 后 $`d_1`$ 消掉了。第一次看会问：为什么组的值正好是 $`a_1`$？

**理解过程**

- 每一批都是“刚好追平就停”。追的过程中被追的数不动、组每步加 1；如果追平后还继续跳过它，组就会超过它，之后还得补回来，白走步数。所以第 1 批结束时组的值正好是 $`a_1`$。
- 前面的步数之所以总会消掉，是因为 $`a_0`$ 和被追的 $`a_i`$ 在第 $`i`$ 批之前都从未被跳过。由引理 1，两者加了同样多的次数，差值一直是原来的 $`a_i - a_0`$。

具体数字 `[1,2,5,7]`：三批分别走 1、4、6 步，正好是 $`2-1`$、$`5-1`$、$`7-1`$，合计 11。

**可迁移思维：** 合并重复步骤时，先找出“到目前为止从未被影响过的元素”，它们之间的差值保持不变，往往能直接给出每批的长度。

## 6. 可迁移知识（Key Takeaways）

本题总结出以下可复用的方法：

1. **Potential Function（势函数）**：本题用 $`\Phi = \sum x_i - n \cdot \min x`$ 衡量离终点还差多少。证明“每步最多减少 1”得到下界，构造“每步恰好减少 1”的方案得到可达。适用于每步代价相同、要求最少步数的问题；前提是能找到每步变化量有界、且在终点为 0 的量。
2. **Batching Repeated Steps（成批合并）**：本题把连续跳过同一个数的步骤合并，一次算出步数，把 $`10^9`$ 级的模拟变成 $`n-1`$ 批。适用于模拟中有大量重复动作的问题；前提是每批的长度可以由当前状态直接算出。

各批长度 $`a_i - a_0`$ 互不影响，所以还能把所有批再合并成一个公式，见[公式解法](../formula/summary.zh-CN.md)。
