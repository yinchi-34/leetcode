## 2. 题意理解（Problem Understanding）

给定长度为 $`n`$ 的整数数组 `nums`。一次操作选择**一个**元素，把它加 1。求使所有元素相等的最少操作次数。

**示例**

- 输入：`nums = [2,1,3]`
- 输出：`3`（第 1 个加 1 次，第 2 个加 2 次，全部变成 3）

- 输入：`nums = [4,4,5]`
- 输出：`2`

**关键要求**

1. 输入约束：$`1 \le n \le 100`$，$`1 \le a_i \le 100`$。
2. 每次操作只改变一个元素，并且只能增加。题目不要求最终值等于某个给定的数。
3. 边界：$`n = 1`$ 或所有元素已经相等时，答案为 0。

## 3. 初始思路（Initial Approach）

### 第一次想到：从 453 联想

453 的[公式解法](../0453-minimum-moves-to-equal-array-elements/formula/summary.zh-CN.md)把“其余 $`n-1`$ 个加 1”反过来看成“一个减 1”，答案是 $`\sum a_i - n \cdot \min a`$。本题的操作是“一个加 1”，正好是那个等价问题的镜像：方向从减变成加，所以基准从最小值换成最大值，答案应为 $`n \cdot \max a - \sum a_i`$。

### 遇到的问题

联想只给出了猜测，还需要确认两点：

1. 镜像是否严格成立，也就是“加”和“减”互换后，“最小值”是否正好换成“最大值”。
2. 本题不需要经过 453 的反向视角，能否直接证明。

### 思维转变

从：

> 本题是 453 的一个变体，要借助 453 的结论。

转变为：

> 本题就是 453 等价问题本身，只差一个符号；而且因为每步只动一个数，可以不借助任何变换直接证明。

453 需要反向视角，是因为它的每一步牵动 $`n-1`$ 个数；本题每一步只动一个数，各元素天然互相独立。

## 4. 算法表达（Algorithm Specification）

**算法名称：** 公式法（Closed-Form Formula）

### 4.1 输入（Input）

$`A = \langle a_0, a_1, \ldots, a_{n-1} \rangle`$

满足：

- $`1 \le n \le 100`$
- $`a_i \in \mathbb{Z}`$，$`1 \le a_i \le 100`$

### 4.2 输出（Output）

最少操作次数 $`k^* = n \cdot \max_i a_i - \sum_i a_i`$。

### 4.3 伪代码（Pseudocode）

下标从 0 开始。

```text
MIN-MOVES(A)
    S ← 0
    M ← A[0]
    for i ← 0 to n - 1
        S ← S + A[i]
        M ← max(M, A[i])
    return n · M - S
```

**状态定义**

- `S`：已遍历元素之和。
- `M`：已遍历元素的最大值。

### 4.4 正确性（Correctness）

**证明方法：下界与可达；另用取负变换从 453 的引理推出同一结论，作为交叉验证。**

**记号**：$`S = \sum_i a_i`$，$`M = \max_i a_i`$。设某个操作方案共 $`k`$ 步，其中第 $`i`$ 个元素被加了 $`c_i \ge 0`$ 次，最终全部等于 $`T`$。

#### 一、正确性依赖的关键条件

1. **计数关系**：每步恰好让一个 $`c_i`$ 加 1，所以 $`k = \sum_i c_i`$，且最终值 $`a_i + c_i = T`$，即 $`c_i = T - a_i`$。
2. **单调性**：$`c_i \ge 0`$，所以 $`T \ge a_i`$ 对每个 $`i`$ 成立，即 $`T \ge M`$。

由计数关系，

```math
k = \sum_{i=0}^{n-1} (T - a_i) = nT - S .
```

步数只取决于最终值 $`T`$，与操作顺序无关。

#### 二、正确性证明

**下界**：任意合法方案都满足 $`T \ge M`$，所以

```math
k = nT - S \ge nM - S .
```

**可达**：取 $`T = M`$，对每个 $`i`$ 把第 $`i`$ 个元素加 $`M - a_i \ge 0`$ 次，按任意顺序执行，最终全部等于 $`M`$，共 $`nM - S`$ 步。

下界与可达相等，所以 $`k^* = nM - S`$。

**交叉验证：由 453 取负得到**

令 $`b_i = -a_i`$。本题中“$`a_j`$ 加 1”就是“$`b_j`$ 减 1”，并且 $`a`$ 全部相等当且仅当 $`b`$ 全部相等。所以本题的最少步数等于对 $`b`$ 求解“每次让一个数减 1”的最少步数，也就是 453 [引理 3](../0453-minimum-moves-to-equal-array-elements/formula/summary.zh-CN.md#44-正确性correctness) 所化成的等价问题。该问题的答案是 $`\sum_i b_i - n \cdot \min_i b_i`$。由 $`\min_i(-a_i) = -\max_i a_i`$，

```math
\sum_i b_i - n \cdot \min_i b_i = -S - n \cdot (-M) = nM - S ,
```

与直接证明的结果一致。取负把“只减不增、终点是最小值”变成“只增不减、终点是最大值”，这就是第 3 节所说的镜像。

#### 三、结论

对任意合法输入，最少步数为 $`nM - S`$。算法一次遍历求出 $`S`$ 和 $`M`$ 后返回 $`nM - S`$，所以算法正确。

### 4.5 复杂度分析（Complexity Analysis）

设输入规模为 $`n`$。

**时间复杂度：Θ(n)**

一次遍历，每个元素做一次加法和一次比较。

**空间复杂度：O(1)**

只用两个变量。

**数值范围**：$`S \le 100 \cdot 100 = 10^4`$，$`nM \le 10^4`$，不存在溢出。

## 5. 思维难点（Learning Notes）

### 难点一：为什么 453 需要反向视角，本题不需要

453 的公式要先证明“其余 $`n-1`$ 个加 1”等价于“一个减 1”，本题直接就能写出 $`c_i = T - a_i`$。

**理解过程**

关键在于每一步牵动几个数。453 每一步改变 $`n-1`$ 个数，第 $`i`$ 个数的变化量取决于全局步数和它被跳过的次数，各元素纠缠在一起，所以要先用平移去掉整体上升。本题每一步只改变一个数，第 $`i`$ 个数的变化量就是它自己被选中的次数 $`c_i`$，各元素一开始就是独立的。

**可迁移思维：** 先看一步操作牵动几个量。只牵动一个量时，总步数可以按元素分开计数；牵动多个量时，先找一个变换把它化成只牵动一个量的形式。

### 难点二：镜像时基准为什么从最小值换成最大值

**理解过程**

基准是由单调方向决定的终点。只减不增时，终点不能高于任何一个数，最高只能取到最小值；只增不减时，终点不能低于任何一个数，最低只能取到最大值。两种情况下，离初始状态最近的终点都是“刚好不需要移动的那个极值”。取负 $`b_i = -a_i`$ 把方向翻转，同时把 $`\min`$ 变成 $`-\max`$，两者一致。

**可迁移思维：** 操作只能单向改变数值时，最优终点是那个方向上的第一个可行值，也就是对应方向的极值。

## 6. 可迁移知识（Key Takeaways）

本题总结出以下可复用的方法：

1. **Lower Bound and Achievability（下界与可达）**：先证明任何方案都至少需要某个步数，再构造一个恰好达到它的方案。本题的下界来自 $`T \ge M`$，构造是“每个数加到最大值”。
2. **Negation Symmetry（取负对称）**：目标只关心“是否全部相等”时，取 $`b_i = -a_i`$ 会把加和减、最大和最小同时互换，已有结论可以直接翻译过来。适用条件是题目对数值本身没有方向性的限制（例如不要求非负）。
3. **Per-element Counting（按元素计数）**：每步只改变一个元素时，总步数等于各元素改变量之和，与顺序无关。
