## 2. 题意理解（Problem Understanding）

给定一个字符串数组 `strs`，把其中互为**字母异位词**的字符串放到同一组，返回所有组。字母异位词是指把一个字符串的字母重新排列（每个字母恰好用一次）得到的字符串，例如 `"eat"`、`"tea"`、`"ate"`。组的顺序、组内字符串的顺序都可以任意。

**示例**

- 输入：`strs = ["eat","tea","tan","ate","nat","bat"]`
- 输出：`[["bat"],["nat","tan"],["ate","eat","tea"]]`

**关键要求**

1. $`1 \le \mathrm{strs.length} \le 10^4`$，$`0 \le \mathrm{strs}[i].\mathrm{length} \le 100`$，`strs[i]` 只含小写英文字母。
2. 每个输入字符串恰好出现在一个组里；重复的字符串（例如两个 `"abc"`）是不同的元素，都要放进同一组。
3. 空串 `""` 是合法输入，所有空串互为字母异位词，自成一组；长度不同的字符串一定不在同一组。

## 4. 算法表达（Algorithm Specification）

**算法名称：** 排序键分组（Sorted-Key Grouping）

### 4.1 输入（Input）

$`S = \langle s_0, s_1, \ldots, s_{n-1} \rangle`$

满足：

- $`1 \le n \le 10^4`$
- 每个 $`s_i`$ 是字母表 $`\Sigma = \{\mathtt{a}, \ldots, \mathtt{z}\}`$ 上的字符串，$`0 \le |s_i| \le 100`$

对字符串 $`s`$ 和字母 $`c \in \Sigma`$，记 $`\mathrm{cnt}_s(c)`$ 为 $`c`$ 在 $`s`$ 中出现的次数。

### 4.2 输出（Output）

称 $`t`$ 是 $`s`$ 的**字母异位词**，记作 $`s \sim t`$，如果存在 $`\{0, \ldots, |s|-1\}`$ 上的一个排列 $`\pi`$，使得 $`|t| = |s|`$ 且对所有 $`j`$ 有 $`t[j] = s[\pi(j)]`$。

在下标集合 $`\{0, \ldots, n-1\}`$ 上定义关系：$`i \equiv j`$ 当且仅当 $`s_i \sim s_j`$。输出 `res` 是若干个组组成的列表，必须满足：

- **不重不漏**：每个下标 $`i`$ 恰好出现在一个组中（组里存放的是字符串 $`s_i`$）。
- **同组必等价**：同一组中任意两个字符串互为字母异位词。
- **等价必同组**：互为字母异位词的两个字符串在同一组中。

也就是说，`res` 恰好是关系 $`\equiv`$ 的全部等价类（引理 0 证明 $`\equiv`$ 是等价关系）。

### 4.3 伪代码（Pseudocode）

伪代码下标从 0 开始。

```text
GROUP-ANAGRAMS-SORTED-KEY(S)
    T ← empty hash table            // 键 → 字符串列表
    for i ← 0 to n - 1
        key ← SORT(s_i)             // s_i 的字母按升序排列
        if key ∉ T
            T[key] ← empty list
        APPEND(T[key], s_i)

    res ← empty list
    for each key in T
        APPEND(res, T[key])
    return res
```

**状态定义**

- `T`：对应代码中的 `groups`，类型是 `map[string][]string`，把排序键映射到这个键下的字符串列表。
- `key`：对应代码中的 `key`，$`s_i`$ 的字母排序后的字符串。代码先用 `[]byte(s)` 复制出字节切片 `b`，`slices.Sort(b)` 原地排序，再用 `string(b)` 转成字符串作键；输入字符串本身不被修改。
- `res`：所有组组成的列表。

代码没有显式的 `if key ∉ T` 分支：读不存在的键时 `groups[key]` 返回 `nil`，而 `append(nil, s)` 会新建切片，效果与伪代码相同。

### 4.4 正确性（Correctness）

**证明方法：等价类划分 + 完全不变量 + 循环不变式**

#### 一、正确性依赖的关键条件

1. **字母异位词等价于字母计数相同**（引理 0）：$`s \sim t \iff \mathrm{cnt}_s = \mathrm{cnt}_t`$。由此 $`\equiv`$ 是等价关系，它的等价类把下标集合划分成互不相交的组。
2. **排序键是完全不变量**（引理 1）：$`\mathrm{SORT}(s) = \mathrm{SORT}(t) \iff s \sim t`$。“$`\Rightarrow`$”保证不会把不同类的字符串合并，“$`\Leftarrow`$”保证不会把同一类拆开。
3. **散列表按键精确分组**（引理 2）：对任何满足 $`f(s) = f(t) \iff s \sim t`$ 的键函数 $`f`$，按 $`f`$ 分组得到的恰好是全部等价类。这一条与键的具体形式无关，[计数键解法](../count-key/summary.zh-CN.md)直接引用。

#### 二、正确性证明

**引理 0**：$`s \sim t \iff \mathrm{cnt}_s = \mathrm{cnt}_t`$；因此 $`\sim`$（从而 $`\equiv`$）是等价关系。

*证明*：

- （$`\Rightarrow`$）$`t[j] = s[\pi(j)]`$ 且 $`\pi`$ 是双射，所以对每个字母 $`c`$，$`t`$ 中等于 $`c`$ 的位置 $`j`$ 与 $`s`$ 中等于 $`c`$ 的位置 $`\pi(j)`$ 一一对应，$`\mathrm{cnt}_t(c) = \mathrm{cnt}_s(c)`$。
- （$`\Leftarrow`$）计数相同则长度相同，$`|s| = \sum_c \mathrm{cnt}_s(c) = \sum_c \mathrm{cnt}_t(c) = |t|`$。对每个字母 $`c`$，把 $`t`$ 中第 $`r`$ 次出现 $`c`$ 的位置 $`j`$ 映射到 $`s`$ 中第 $`r`$ 次出现 $`c`$ 的位置，记为 $`\pi(j)`$。由于两边 $`c`$ 的出现次数相同，这在每个字母内部是双射；各字母的位置集合互不相交且覆盖全部位置，所以 $`\pi`$ 是排列，并且 $`t[j] = c = s[\pi(j)]`$。

“计数相同”显然满足自反、对称、传递，所以 $`\sim`$ 是等价关系，$`\equiv`$ 也是。由等价关系与划分的对应（CLRS 附录 B.2 定理 B.1），$`\equiv`$ 的等价类把 $`\{0, \ldots, n-1\}`$ 划分成互不相交、并集为全集的若干组。

**引理 1**：$`\mathrm{SORT}(s) = \mathrm{SORT}(t) \iff s \sim t`$。

*证明*：排序只重排字母，不改变计数，所以 $`\mathrm{cnt}_{\mathrm{SORT}(s)} = \mathrm{cnt}_s`$。另一方面，按字母升序排列的字符串由计数唯一确定：

```math
\mathrm{SORT}(s) = \mathtt{a}^{\mathrm{cnt}_s(\mathtt{a})}\, \mathtt{b}^{\mathrm{cnt}_s(\mathtt{b})} \cdots \mathtt{z}^{\mathrm{cnt}_s(\mathtt{z})}
```

其中 $`c^m`$ 表示 $`m`$ 个 $`c`$ 连写。

- （$`\Leftarrow`$）$`s \sim t`$ 时由引理 0 有 $`\mathrm{cnt}_s = \mathrm{cnt}_t`$，代入上式得 $`\mathrm{SORT}(s) = \mathrm{SORT}(t)`$。
- （$`\Rightarrow`$）$`\mathrm{SORT}(s) = \mathrm{SORT}(t)`$ 时，$`\mathrm{cnt}_s = \mathrm{cnt}_{\mathrm{SORT}(s)} = \mathrm{cnt}_{\mathrm{SORT}(t)} = \mathrm{cnt}_t`$，由引理 0 得 $`s \sim t`$。

**引理 2（按键分组）**：设键函数 $`f`$ 满足 $`f(s) = f(t) \iff s \sim t`$，算法按 $`f`$ 分组。则输出恰好是 $`\equiv`$ 的全部等价类，且每组内字符串按输入顺序排列。

**循环不变式**

在第一个 `for` 循环每次迭代开始时（已处理 $`s_0, \ldots, s_{i-1}`$）：

**不变式 I：键集合**

$`T`$ 的键集合恰好是 $`\{f(s_j) : 0 \le j < i\}`$。

**不变式 II：组内容**

对 $`T`$ 中每个键 $`k`$，$`T[k]`$ 是 $`\langle s_j : 0 \le j < i,\ f(s_j) = k \rangle`$，即前 $`i`$ 个字符串中键为 $`k`$ 的那些，按下标递增排列。

**初始化（Initialization）**

$`i = 0`$，$`T`$ 为空，两个集合都为空，成立。

**保持（Maintenance）**

假设处理 $`s_i`$ 之前不变式成立，记 $`k = f(s_i)`$。

- **情况一：$`k \notin T`$**。算法新建 $`T[k] = \langle s_i \rangle`$。由不变式 I，前 $`i`$ 个字符串中没有键为 $`k`$ 的，所以 $`\langle s_i \rangle`$ 正是前 $`i+1`$ 个字符串中键为 $`k`$ 的序列；其他键的列表不变。键集合增加了 $`f(s_i)`$，两条不变式都成立。
- **情况二：$`k \in T`$**。算法把 $`s_i`$ 追加到 $`T[k]`$ 末尾。原列表是前 $`i`$ 个中键为 $`k`$ 的字符串，按下标递增；追加下标更大的 $`s_i`$ 后，正是前 $`i+1`$ 个中键为 $`k`$ 的字符串，仍按下标递增。其他键的列表和键集合不变，不变式成立。

**终止（Termination）**

循环在 $`i = n`$ 时结束，此时 $`T`$ 的每个键 $`k`$ 对应列表 $`\langle s_j : f(s_j) = k \rangle`$。第二个循环把每个列表原样放进 `res`。

- **不重不漏**：每个下标 $`j`$ 恰好属于键 $`f(s_j)`$ 的列表，不属于其他键的列表。
- **同组必等价**：同组的 $`s_j, s_{j'}`$ 满足 $`f(s_j) = f(s_{j'})`$，由 $`f`$ 的“$`\Rightarrow`$”方向得 $`s_j \sim s_{j'}`$。
- **等价必同组**：若 $`s_j \sim s_{j'}`$，由“$`\Leftarrow`$”方向得 $`f(s_j) = f(s_{j'})`$，两者在同一个列表中。

所以每个列表都是一个完整的等价类，且每个等价类恰好对应一个键。

#### 三、结论

由引理 1，排序键满足引理 2 的条件，所以算法对所有合法输入都输出 $`\equiv`$ 的全部等价类，与题目要求一致。Go `map` 的遍历顺序是随机的，只影响组的先后，题目允许任意顺序；组内顺序由不变式 II 保证是输入顺序。

### 4.5 复杂度分析（Complexity Analysis）

设 $`n`$ 为字符串个数，$`\ell_i = |s_i|`$，$`L = \sum_i \ell_i`$ 为总长度，$`k = \max_i \ell_i`$（本题 $`k \le 100`$），$`g`$ 为组数（$`g \le n`$）。下面的“期望”指散列表单次操作的期望代价（见[总体笔记 §2.1](../../README.zh-CN.md)）。

**时间复杂度：期望 O(n k log k)**

处理字符串 $`s_i`$ 的各步：

- `[]byte(s)` 复制与 `string(b)` 转换：各 $`O(\ell_i)`$。
- `slices.Sort(b)`：Go 的 `slices.Sort` 是模式消除快速排序（pdqsort），在递归过深时改用堆排序，最坏 $`O(\ell_i \log \ell_i)`$。
- 查表与追加：计算字符串键的散列值要读完整个键，$`O(\ell_i)`$；期望 $`O(1)`$ 次键比较，每次 $`O(\ell_i)`$；`append` 摊还 $`O(1)`$。合计期望 $`O(\ell_i)`$。

第二个循环遍历 $`g`$ 个键，$`O(g)`$。总计期望

```math
O\Bigl(n + \sum_{i} \ell_i \log \ell_i\Bigr) \le O(n + L \log k) \le O(n k \log k)
```

单独写出 $`n`$ 是因为空串的 $`\ell_i = 0`$，但每个字符串至少要做一次查表。

**空间复杂度：O(n + L)**

- 散列表的键：$`g`$ 个不同的排序串，总长度不超过 $`L`$，$`O(L)`$。
- 散列表的条目和列表：$`g`$ 个条目、共 $`n`$ 个字符串头，$`O(n)`$。这些列表直接作为输出，字符串内容与输入共享，没有复制。
- 临时切片 `b`：$`O(k)`$，每轮循环重新分配，旧的可被回收。
- `res`：$`g`$ 个切片头，$`O(g)`$。

计入输出时总空间 $`O(n + L)`$；不计输出（即不计 $`n`$ 个字符串头和 `res`）时，额外空间仍要 $`O(g + L)`$ 存放键，最坏（没有任何两个字符串互为异位词）为 $`O(n + L)`$。

### 4.6 实现细节：Go 与 Python（Implementation Notes）

- **构造键**：Go 要先转成 `[]byte`，`slices.Sort` 排序后再转回 `string`；Python 一行写成 `"".join(sorted(s))`。两者都是 $`O(k \log k)`$。
- **分组的顺序**：Go 的 `map` 遍历顺序随机，所以返回的组顺序每次可能不同；Python 的 `dict` 按插入顺序遍历，组按各自第一个元素出现的顺序返回。题目允许任意顺序，测试也先把分组排序再比较。见[哈希表](../../../../docs/LANGUAGE_NOTES.zh-CN.md#哈希表)。
- **追加到组**：Go 的 `groups[key] = append(groups[key], s)` 依赖读不存在的键返回 `nil`；Python 用 `defaultdict(list)`。

## 5. 思维难点（Learning Notes）

### 难点一：什么样的键才能用来分组？

分组的本质是：给每个字符串算一个键，键相同就放一起。键选得不对，结果会悄悄出错，而且常见用例未必能测出来。

**理解过程**

键函数 $`f`$ 要同时满足两个方向。只满足“$`s \sim t \Rightarrow f(s) = f(t)`$”时不会拆散同一组，但可能把不同组合并，例如只用字母**集合**作键，`"aab"` 和 `"abb"` 会被错误地合并。只满足“$`f(s) = f(t) \Rightarrow s \sim t`$”时不会合并错，但可能拆散同一组，例如直接用原串作键，`"eat"` 和 `"tea"` 会被分开。排序后的字符串两个方向都满足（引理 1），所以是合格的键。测试中的 `Same letter set, different multiplicities` 用例专门检查第一种错误。

**可迁移思维：** 设计分组键时，把它当作等价关系的**完全不变量**来检查：等价的对象键必须相同，键相同的对象必须等价。只验证一个方向的键是常见错误来源。

### 难点二：Go 里为什么不能直接用排序后的 `[]byte` 作键？

Go `map` 的键必须是可比较类型，切片不可比较，`map[[]byte][]string` 无法通过编译。

**理解过程**

所以代码先把 `b` 转成 `string(b)` 再作键。这个转换会复制一份字节，键与 `b` 不共享内存，之后即使修改 `b` 也不影响表中的键。同样，`[]byte(s)` 也会复制，排序不会改动输入的字符串。另一种做法是用定长数组作键，数组是可比较的，这正是[计数键解法](../count-key/summary.zh-CN.md)的写法。

**可迁移思维：** 在 Go 中用复合数据作 `map` 的键时，先确认它是否可比较：字符串、数组、只含可比较字段的结构体可以，切片、`map`、函数不行。不可比较的数据要先编码成字符串或定长数组。

### 难点三：为什么不两两比较？

最直接的做法是对每个字符串，与已有每组的代表逐一比较是否互为异位词，这正是测试里的参考实现 `bruteForce`。

**理解过程**

逐一比较时，一个字符串最多要和 $`g`$ 个代表各比较一次，每次 $`O(k)`$，总时间 $`O(n g k)`$，最坏 $`O(n^2 k)`$。把每个字符串变成规范形式后，“和谁是一组”就从“与所有代表比较”变成“查一次表”，期望一次查表就能找到所属的组。

**可迁移思维：** 当需要把对象按某种等价关系归类时，先找一个规范形式，再用散列表按规范形式查表，就能把两两比较的平方代价降到线性次查表。

## 6. 可迁移知识（Key Takeaways）

本题总结出以下可复用的方法：

1. **Canonical Form（规范形式）**：在本题中，排序后的字符串是每个异位词类的唯一代表。适用于“在某种变换下视为相同”的对象的判等和分组，例如排列（排序）、循环移位（取字典序最小的旋转）、整体平移（减去首元素）。成立条件是规范形式必须是完全不变量，且计算代价可接受。
2. **Group by Key（按键分组）**：在本题中用 `map[键][]元素` 一遍扫描完成分组，组内保持输入顺序。适用于任何能算出完全不变量的等价分类问题；限制是只能分组，不能回答“两个组之间谁大”这类有序问题，组的输出顺序也不确定。
3. **Equivalence Classes（等价类）**：在本题中先证明“互为异位词”是等价关系，分组结果才是良定义的划分。适用于需要判断“分组”是否有意义的问题；如果关系不传递（例如“只差一个字母”），就不能用按键分组，要改用并查集或图的连通分量。
4. **Sorting as Normalization（排序作归一化）**：在本题中排序消除了字母的位置信息，只保留计数。适用于只关心多重集、不关心顺序的比较；代价是 $`O(k \log k)`$，字母表小而固定时可以用计数代替（见[计数键解法](../count-key/summary.zh-CN.md)）。

**一句话总结**

互为异位词的字符串排序后完全相同，排序后不同的一定不是异位词，所以把排序结果当作散列表的键，一遍扫描就能把每个字符串放进它唯一的组。
