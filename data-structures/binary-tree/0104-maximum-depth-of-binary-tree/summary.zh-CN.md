## 2. 题意理解（Problem Understanding）

给定一棵二叉树的根结点 `root`，返回它的最大深度。最大深度是从根结点到最远叶子结点的路径上的**结点数**。叶子结点是没有子结点的结点。

**示例**

- 输入：`root = [3,9,20,null,null,15,7]`
- 输出：`3`

根 3 的左孩子 9 是叶子，右孩子 20 下面还有 15 和 7，最长的根到叶路径是 3 → 20 → 15（或 3 → 20 → 7），共 3 个结点。

- 输入：`root = [1,null,2]`
- 输出：`2`

**关键要求**

1. 输入约束：结点数在 $`[0, 10^4]`$ 内，$`-100 \le \mathrm{Node.val} \le 100`$。结点值与答案无关。
2. 深度按结点数计，不按边数计：只有根结点的树深度为 1。
3. 边界：空树（`root == nil`）的深度为 0；树可能退化成一条链，深度等于结点数 $`10^4`$。

## 4. 算法表达（Algorithm Specification）

**算法名称：** 递归深度优先搜索（Recursive Depth-First Search），按后序组合子树结果

### 4.1 输入（Input）

一棵二叉树 $`T`$，按递归方式定义：$`T`$ 要么是空树 $`\varnothing`$，要么是三元组 $`(r, L, R)`$，其中 $`r`$ 是根结点，$`L`$、$`R`$ 分别是左、右子树（也是二叉树）。

记 $`\lvert T \rvert`$ 为 $`T`$ 的结点数，满足：

- $`0 \le \lvert T \rvert \le 10^4`$；
- 每个结点只有一个父结点（根除外），沿孩子指针走不会回到已经经过的结点，即输入确实是一棵树。

非空树 $`(r, L, R)`$ 中，$`\lvert T \rvert = 1 + \lvert L \rvert + \lvert R \rvert`$。左右孩子都为空的结点称为叶子。

### 4.2 输出（Output）

**根到叶路径**是从根出发、每一步走到当前结点的一个孩子、最后停在叶子上的结点序列。定义

```math
D(T) =
\begin{cases}
0, & T = \varnothing \\
\max \{\, \text{路径 } P \text{ 的结点数} : P \text{ 是 } T \text{ 的根到叶路径} \,\}, & T \ne \varnothing
\end{cases}
```

输出 $`D(T)`$。

### 4.3 伪代码（Pseudocode）

```text
MAX-DEPTH(x)                          ▷ x 是子树的根，可能为 NIL
    if x == NIL
        return 0
    return MAX(MAX-DEPTH(x.left), MAX-DEPTH(x.right)) + 1
```

算法直接返回表达式，没有结果变量。代码中的辅助函数 `max` 对应伪代码的 `MAX`，返回两个整数中较大的一个。

**状态定义**

- `x`：当前子树的根；`x == NIL` 表示空子树。
- 返回值：以 `x` 为根的子树的 $`D`$ 值。

### 4.4 正确性（Correctness）

**证明方法：对结点数的强归纳（结构归纳）**

#### 一、正确性依赖的关键条件

1. **输入是一棵树**（题目条件）：子树 $`L`$、$`R`$ 互不相交且都不含 $`r`$，所以 $`\lvert L \rvert, \lvert R \rvert < \lvert T \rvert`$。这保证了递归规模严格变小，从而一定终止，也是归纳能进行的前提。
2. **空树深度为 0，非空树深度至少为 1**（由定义）：任何非空树至少有一条根到叶路径，且路径至少包含根。
3. **引理 1（深度的递归结构）**：对非空树 $`T = (r, L, R)`$，有 $`D(T) = 1 + \max(D(L), D(R))`$。

**引理 1 的证明。** 分两种情况。

- **情况一：$`L = R = \varnothing`$。** $`r`$ 是叶子，唯一的根到叶路径是 $`\langle r \rangle`$，所以 $`D(T) = 1 = 1 + \max(0, 0)`$。
- **情况二：至少一个孩子非空。** 此时 $`r`$ 不是叶子，任一根到叶路径的第二个结点是某个非空孩子子树 $`C`$ 的根，路径去掉 $`r`$ 后正是 $`C`$ 的一条根到叶路径（$`C`$ 中结点的孩子与在 $`T`$ 中相同，所以叶子也相同）。反过来，在 $`C`$ 的任一根到叶路径前面接上 $`r`$，得到 $`T`$ 的一条根到叶路径。因此

```math
D(T) = 1 + \max \{\, D(C) : C \in \{L, R\},\ C \ne \varnothing \,\}
```

若某个孩子为空，它的 $`D`$ 值是 0，而另一个非空孩子的 $`D`$ 值至少是 1（关键条件 2），把 0 加入取最大值的范围不改变结果，所以 $`D(T) = 1 + \max(D(L), D(R))`$。∎

#### 二、正确性证明

**定理。** 对任意满足 4.1 条件的二叉树 $`T`$，`MAX-DEPTH(T)` 终止并返回 $`D(T)`$。

*证明*：对 $`n = \lvert T \rvert`$ 做强归纳。

**基础（$`n = 0`$）**：$`T = \varnothing`$，`x == NIL` 成立，返回 0，等于 $`D(\varnothing)`$。

**归纳步（$`n \ge 1`$）**：假设对所有结点数小于 $`n`$ 的树结论成立。$`T = (r, L, R)`$ 非空，跳过基础分支。由关键条件 1，$`\lvert L \rvert + \lvert R \rvert = n - 1`$，两者都小于 $`n`$，由归纳假设，两次递归调用都终止，分别返回 $`D(L)`$ 和 $`D(R)`$。`MAX` 返回其中较大者，再加 1，结果是 $`1 + \max(D(L), D(R))`$。由引理 1，它等于 $`D(T)`$。∎

两次递归调用的先后顺序不影响结果：它们只读取各自的子树，不修改任何结点。

#### 三、结论

空树按定义返回 0；非空树的最大深度由引理 1 归结为两棵更小子树的最大深度，归纳假设保证这两个值已经算对。因此算法对所有合法输入返回正确的最大深度。

### 4.5 复杂度分析（Complexity Analysis）

设 $`n = \lvert T \rvert`$，$`h = D(T)`$。

**时间复杂度：$`\Theta(n)`$**

数一数调用次数。每个结点恰好作为一次非空调用的参数：根由外部调用，其余结点由它唯一的父结点调用。空调用的次数等于空孩子指针的个数：$`n \ge 1`$ 时共有 $`2n`$ 个孩子指针，其中 $`n - 1`$ 个指向结点，剩下 $`n + 1`$ 个为空；$`n = 0`$ 时只有一次空调用。所以调用总数是

```math
n + (n + 1) = 2n + 1
```

每次调用除递归外只做常数次操作，总时间为 $`\Theta(n)`$。任何正确算法都必须检查每个结点（漏看任何一个结点，都可能漏掉挂在它下面的更深路径），所以 $`\Omega(n)`$ 不可避免。

**空间复杂度：$`\Theta(h)`$**

算法不分配任何堆内存，额外空间全部来自递归栈。递归链从根开始，每深入一层就沿一条向下的路径走一步，最深时走到某片叶子再多调用一次空孩子，所以栈的最大深度是 $`h + 1`$（$`n = 0`$ 时为 1），即 $`\Theta(h)`$。

- **最坏情况**：树退化成一条链，$`h = n`$，栈深度为 $`\Theta(n)`$。测试中的 `left_chain_max_nodes` 和 `right_chain_max_nodes` 就是 $`10^4`$ 个结点的链。
- **最好情况**：完全二叉树，$`h = \lfloor \log_2 n \rfloor + 1`$，栈深度为 $`\Theta(\log n)`$。

Go 的 goroutine 栈按需增长，$`10^4`$ 层递归可以正常运行。

## 5. 思维难点（Learning Notes）

### 难点一：为什么一个孩子为空时不需要特判？

只有一个孩子的结点不是叶子，从它出发的根到叶路径只能走进非空的那一侧。看起来似乎要写成“若左空则看右，若右空则看左”。

**理解过程**

引理 1 的情况二说明，真正的式子是“对非空孩子取最大值”。空孩子返回 0，而非空孩子至少返回 1，所以把空孩子一起放进 `max` 也不会被选中，结果不变。也就是说，0 在这里起到了取最大值的“中性值”作用：对非负数 $`a`$，$`\max(0, a) = a`$。

对比 [111. 二叉树的最小深度](https://leetcode.cn/problems/minimum-depth-of-binary-tree/)：如果照搬成 `min(minDepth(L), minDepth(R)) + 1`，一个孩子为空时 `min` 会选中 0，把“走进空子树”当成一条路径，答案就错了。那道题必须对“一个孩子为空”单独处理。

**可迁移思维：** 用递归合并子问题时，先检查基础情况的返回值对合并运算是否“中性”。对取最大值来说 0 是中性的（值非负时），对取最小值来说 0 不是。不中性时就要把空子树单独排除。

### 难点二：深度按结点数计，还是按边数计？

**理解过程**

本题的“最大深度”数的是路径上的结点数，只有根的树深度为 1。CLRS 附录 B.5 定义的结点深度和树高数的是边数，只有根的树高度为 0。对非空树，两者正好相差 1：本题答案等于 CLRS 意义下的树高加 1。

写代码时，这个差别体现在基础情况和加 1 的位置上：本题空树返回 0，每层加 1，叶子就得到 1。若题目改成按边数计，常见写法是让空树返回 $`-1`$，叶子得到 0。

**可迁移思维：** 遇到“深度”“高度”“层数”时，先确认按结点数还是边数计，以及空树取什么值。基础情况的返回值要和这个定义一致。

### 难点三：递归深度与树高

**理解过程**

递归栈的深度等于树高，而不是 $`\log n`$。题目没有保证树是平衡的，$`10^4`$ 个结点可以排成一条链，递归深度就是 $`10^4`$。Go 的栈会按需增长，所以本题没有问题；在默认栈较小的环境里，可以改用显式栈的 DFS，或者用队列按层做 BFS，每处理完一层计数加 1。

另外，代码自己定义了 `max`。Go 1.21 起 `max` 已是内置函数，仓库的 `go.mod` 要求 Go 1.22，所以这个辅助函数可以删掉直接用内置的；保留它也合法，包级定义会在本包内遮蔽内置的 `max`，行为相同。

**可迁移思维：** 估计递归解法的空间时，要用递归树的实际深度，二叉树上就是树高；只有在平衡性有保证时才能写成 $`O(\log n)`$。

## 6. 可迁移知识（Key Takeaways）

本题总结出以下可复用的方法：

1. **Postorder Aggregation（后序合并子树信息）**：在本题中，先求出左右子树的深度，再在根结点合并成 $`1 + \max`$。适用于树高、结点数、子树和、是否平衡、直径等“由子树结果算出整棵树结果”的问题。条件是根的答案只依赖左右子树各自的答案（或少量附加信息）。
2. **Structural Induction（结构归纳）**：在本题中，对结点数做强归纳，归纳假设直接对应两次递归调用的返回值。适用于证明几乎所有树上的递归算法。前提是子树规模严格小于原树，这由“输入是一棵树”保证。
3. **Neutral Base Case（中性的基础情况）**：在本题中，空树返回 0，对取最大值是中性的，所以一个孩子为空时不需要特判。适用于设计递归的基础情况。限制：换成取最小值等运算时 0 不再中性，需要单独排除空子树（见 111 题）。
4. **Recursion Depth Equals Tree Height（递归深度等于树高）**：在本题中，额外空间是 $`\Theta(h)`$，最坏为 $`\Theta(n)`$。适用于估计任何树上递归的栈空间。只有树高有保证（如平衡树）时才能写成 $`O(\log n)`$。
