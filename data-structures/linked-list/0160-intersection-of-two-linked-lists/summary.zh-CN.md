## 2. 题意理解（Problem Understanding）

给定两条单链表的表头 `headA` 和 `headB`，找出并返回两条链表相交的起始结点；不相交时返回 `nil`。“相交”指两条链表从某个结点起共用同一批结点（同一块内存），而不是值相同。函数返回后，链表必须保持原有结构。

评测时用 `intersectVal`、`listA`、`listB`、`skipA`、`skipB` 描述输入：`listB` 的前 `skipB` 个结点之后，接到 `listA` 的第 `skipA` 个结点（0-based）上。函数只能看到 `headA` 和 `headB`。

**示例**

- 输入：`intersectVal = 8, listA = [4,1,8,4,5], listB = [5,6,1,8,4,5], skipA = 2, skipB = 3`
- 输出：值为 `8` 的结点

A 中的第一个 `1` 和 B 中的 `1` 是两个不同的结点，值相同但不是相交点；相交从值为 `8` 的结点开始。

- 输入：`intersectVal = 0, listA = [2,6,4], listB = [1,5], skipA = 3, skipB = 2`
- 输出：`null`

**关键要求**

1. 输入约束：$`1 \le m, n \le 3 \times 10^4`$，$`1 \le \mathrm{Node.val} \le 10^5`$；整个链式结构中没有环。
2. 判断相交看结点是否是同一个（指针相等），不看结点值。
3. 不能修改链表结构。进阶要求：时间 $`O(m + n)`$，额外空间 $`O(1)`$。
4. 边界：可能完全不相交；也可能从表头就相交（两条链表是同一条），或一条是另一条的后缀。

## 4. 算法表达（Algorithm Specification）

**算法名称：** 双指针换头遍历（Two Pointers with Head Switching）

### 4.1 输入（Input）

两条无环单链表 $`A`$、$`B`$，表头分别为 `headA`、`headB`，结点数分别为 $`m`$、$`n`$。把它们按顺序写成结点序列（0-based）：

```math
A = \langle A_0, A_1, \ldots, A_{m-1} \rangle, \qquad B = \langle B_0, B_1, \ldots, B_{n-1} \rangle
```

其中 $`A_{i+1} = A_i.\mathit{next}`$，$`A_{m-1}.\mathit{next} = \mathrm{NIL}`$，$`B`$ 同理。满足：

- $`1 \le m, n \le 3 \times 10^4`$；
- 链式结构无环，所以同一条链表中的结点两两不同。

### 4.2 输出（Output）

若 $`A`$ 与 $`B`$ 有公共结点，输出 $`A`$ 中第一个同时出现在 $`B`$ 中的结点；否则输出 $`\mathrm{NIL}`$。链表结构不变。

### 4.3 伪代码（Pseudocode）

```text
GET-INTERSECTION-NODE(headA, headB)
    a = headA
    b = headB
    while a ≠ b                       ▷ 比较的是结点本身，不是结点的值
        if a ≠ NIL
            a = a.next
        else a = headB
        if b ≠ NIL
            b = b.next
        else b = headA
    return a
```

循环结束时 `a == b`，直接返回 `a`，没有单独的结果变量。

**状态定义**

- `a`：从 `headA` 出发的指针，先走完 $`A`$，在 $`\mathrm{NIL}`$ 处停一步，再从 `headB` 走 $`B`$。
- `b`：从 `headB` 出发的指针，先走完 $`B`$，在 $`\mathrm{NIL}`$ 处停一步，再从 `headA` 走 $`A`$。
- 两个指针每轮各前进一步，所以第 $`t`$ 轮开始时两者都已走了 $`t`$ 步。

### 4.4 正确性（Correctness）

**证明方法：先确定链表的形状（引理 1），再写出两个指针第 $`t`$ 步的位置（引理 2），最后对“第一次相遇”分情况讨论**

#### 一、正确性依赖的关键条件

1. **每个结点只有一个 `next`**（链表的定义）：从同一个结点出发，往后经过的结点序列是唯一确定的。
2. **无环**（题目条件）：每条链表的结点两两不同，并且一定在有限步内走到 $`\mathrm{NIL}`$。
3. **引理 1（相交部分是公共尾部）**：存在 $`\alpha, \beta, c \ge 0`$，使得 $`m = \alpha + c`$，$`n = \beta + c`$，并且
   - 当 $`k < c`$ 时 $`A_{\alpha + k} = B_{\beta + k}`$，记作 $`C_k`$；
   - 私有前缀 $`P_A = \langle A_0, \ldots, A_{\alpha-1} \rangle`$ 中的结点都不在 $`B`$ 中，$`P_B = \langle B_0, \ldots, B_{\beta-1} \rangle`$ 中的结点都不在 $`A`$ 中。

   于是正确答案是 $`C_0`$（当 $`c > 0`$）或 $`\mathrm{NIL}`$（当 $`c = 0`$）。

**引理 1 的证明。** 若 $`A`$、$`B`$ 没有公共结点，取 $`\alpha = m`$，$`\beta = n`$，$`c = 0`$ 即可。否则设 $`\alpha`$ 是 $`A`$ 中第一个公共结点的下标，它在 $`B`$ 中的下标为 $`\beta`$（$`B`$ 中结点两两不同，所以下标唯一）。由关键条件 1，从 $`A_\alpha = B_\beta`$ 出发两边往后的序列完全相同，直到同时到达 $`\mathrm{NIL}`$，所以 $`m - \alpha = n - \beta`$，记为 $`c \ge 1`$，且 $`A_{\alpha+k} = B_{\beta+k}`$。$`P_A`$ 中的结点不在 $`B`$ 中，这正是 $`\alpha`$ 的定义。若某个 $`B_j`$（$`j < \beta`$）在 $`A`$ 中，它在 $`A`$ 中的下标不小于 $`\alpha`$（$`\alpha`$ 是第一个公共结点），即 $`B_j = C_k = B_{\beta+k}`$，而 $`j < \beta + k`$，与 $`B`$ 中结点两两不同矛盾。∎

**引理 2（第 $`t`$ 步的位置）。** 定义两个序列

```math
S_A = \langle A_0, \ldots, A_{m-1}, \mathrm{NIL}, B_0, \ldots, B_{n-1}, \mathrm{NIL} \rangle, \qquad
S_B = \langle B_0, \ldots, B_{n-1}, \mathrm{NIL}, A_0, \ldots, A_{m-1}, \mathrm{NIL} \rangle
```

长度都是 $`m + n + 2`$。对 $`0 \le t \le m + n + 1`$，若循环在第 $`t`$ 轮之前没有结束，则此时 `a` $`= S_A[t]`$，`b` $`= S_B[t]`$。

*证明*：$`t = 0`$ 时 `a = headA` $`= A_0`$。每一轮中，`a` 在非 $`\mathrm{NIL}`$ 结点上取 `next`，在 $`\mathrm{NIL}`$ 上换到 `headB`；按 $`A_i.\mathit{next}`$ 的定义，这正好把 $`S_A[t]`$ 变成 $`S_A[t+1]`$（$`A_{m-1}`$ 之后是 $`\mathrm{NIL}`$，$`\mathrm{NIL}`$ 之后是 $`B_0`$，$`B_{n-1}`$ 之后是 $`\mathrm{NIL}`$）。`b` 同理。∎

记 $`T = \alpha + \beta + c + 1`$。因为 $`T = m + 1 + \beta = n + 1 + \alpha`$，

```math
S_A[T] = B_\beta, \qquad S_B[T] = A_\alpha
```

其中当 $`c = 0`$ 时 $`B_\beta = B_n`$ 指序列中 $`B`$ 之后的那个 $`\mathrm{NIL}`$，$`A_\alpha`$ 同理。

#### 二、正确性证明

**定理。** `GET-INTERSECTION-NODE` 的循环最多执行 $`T`$ 轮后结束，返回值是 $`C_0`$（$`c > 0`$）或 $`\mathrm{NIL}`$（$`c = 0`$）。

*证明*：循环在第一个满足 $`S_A[t] = S_B[t]`$ 的 $`t`$ 处结束并返回 $`S_A[t]`$（引理 2）。先看 $`0 \le t \le T`$ 范围内，$`S_A`$ 和 $`S_B`$ 中各结点出现的位置：

| 结点 | 在 $`S_A[0..T]`$ 中的下标 | 在 $`S_B[0..T]`$ 中的下标 |
|---|---|---|
| $`A_i \in P_A`$ | $`i`$ | $`n + 1 + i`$ |
| $`B_j \in P_B`$ | $`m + 1 + j`$ | $`j`$ |
| $`C_k`$（$`c > 0`$） | $`\alpha + k`$；$`k = 0`$ 时还有 $`T`$ | $`\beta + k`$；$`k = 0`$ 时还有 $`T`$ |
| $`\mathrm{NIL}`$ | $`m`$；$`c = 0`$ 时还有 $`T`$ | $`n`$；$`c = 0`$ 时还有 $`T`$ |

这张表成立，是因为 $`S_A[0..T]`$ 恰好是 $`A`$、$`\mathrm{NIL}`$、$`P_B`$、$`S_A[T]`$，而由引理 1，$`P_B`$ 不含 $`A`$ 的结点，$`P_A`$ 不含 $`B`$ 的结点；$`S_B`$ 对称。

由表可知，私有结点不可能使 $`S_A[t] = S_B[t]`$：$`i \ne n + 1 + i`$，$`m + 1 + j \ne j`$。所以相遇只可能发生在公共结点或 $`\mathrm{NIL}`$ 上。分两种情况。

- **情况一：$`\alpha = \beta`$（私有前缀等长，此时 $`m = n`$）。** 对 $`t < \alpha`$，两边都是私有结点，不相遇。
  - 若 $`c > 0`$：$`t = \alpha`$ 时 $`S_A[\alpha] = C_0 = S_B[\alpha]`$，第一次相遇，返回 $`C_0`$。
  - 若 $`c = 0`$：$`t = \alpha = m = n`$ 时两边都是 $`\mathrm{NIL}`$，第一次相遇，返回 $`\mathrm{NIL}`$。
- **情况二：$`\alpha \ne \beta`$（此时 $`m \ne n`$）。** 由表，$`C_k`$ 在两边的下标 $`\alpha + k \ne \beta + k`$，$`\mathrm{NIL}`$ 的下标 $`m \ne n`$，所以 $`t < T`$ 时不相遇。$`t = T`$ 时 $`S_A[T] = B_\beta`$，$`S_B[T] = A_\alpha`$：
  - 若 $`c > 0`$：两者都是 $`C_0`$，返回 $`C_0`$；
  - 若 $`c = 0`$：两者都是 $`\mathrm{NIL}`$，返回 $`\mathrm{NIL}`$。

两种情况下第一次相遇都发生在 $`t \le T \le m + n + 1`$，所以循环在引理 2 适用的范围内结束，返回值正确。算法只读 `next`，不写任何结点，链表结构不变。∎

#### 三、结论

引理 1 把两条链表拆成“各自的私有前缀 + 公共尾部”，正确答案就是公共尾部的第一个结点。两个指针走完自己的链表再走对方的链表，到第 $`T`$ 步时都恰好走了 $`\alpha + \beta + c + 1`$ 步，同时到达公共尾部的起点（或同时到达 $`\mathrm{NIL}`$）；私有结点在两个序列中的位置永远错开，不会造成提前的错误相遇。

### 4.5 复杂度分析（Complexity Analysis）

设两条链表的长度为 $`m`$、$`n`$，$`\alpha`$、$`\beta`$、$`c`$ 如引理 1。

**时间复杂度：$`O(m + n)`$**

由定理的证明，循环执行的轮数是

```math
t^* =
\begin{cases}
\alpha, & \alpha = \beta,\ c > 0 \\
m, & \alpha = \beta,\ c = 0 \\
\alpha + \beta + c + 1, & \alpha \ne \beta
\end{cases}
```

每轮常数次操作，所以总时间 $`\Theta(t^*) = O(m + n)`$。最坏情况是长度不同且不相交，$`t^* = m + n + 1`$，测试 `max_length_unequal_no_intersection` 就是这种情况。最好情况是 `headA == headB`，$`t^* = 0`$。

**空间复杂度：$`\Theta(1)`$**

只用了 `a`、`b` 两个指针，不分配堆内存，没有递归，也不修改链表。

- 跳过 `nil` 这一步，在最后一个结点直接换到另一条链表的表头（`if a.Next == nil { a = headB }`）：所有不相交的用例都超时。原因是两个指针永远不会同时为 `nil`，而私有结点又不会相遇，循环不会结束。

## 5. 思维难点（Learning Notes）

### 难点一：为什么交换表头就能“对齐”？

两条链表长度不同时，同时从表头出发，两个指针到达公共尾部的时间不同。常见的做法是先求出两条链表的长度，让长的那条先走 $`\lvert m - n \rvert`$ 步。

**理解过程**

换头遍历是不求长度的“对齐”。指针 `a` 走过的路是 $`P_A`$、公共尾部、$`\mathrm{NIL}`$、$`P_B`$，然后到达公共尾部的起点；指针 `b` 走过的路是 $`P_B`$、公共尾部、$`\mathrm{NIL}`$、$`P_A`$，然后到达同一个起点。两段路的长度都是 $`\alpha + c + 1 + \beta`$，加法交换顺序不改变总和，所以它们在同一步到达。先求长度的做法也是 $`O(m + n)`$ 时间、$`O(1)`$ 空间，只是要多写两次遍历；两者是同一个想法：消掉 $`\alpha - \beta`$ 这个差。

**可迁移思维：** 两个过程“长度不同，需要对齐”时，可以让每一方把对方的那一段也走一遍，总长度自然相同。

### 难点二：为什么 `nil` 也要算作一步？

伪代码中，指针走到 $`\mathrm{NIL}`$ 时不立即跳到另一条链表，而是在 $`\mathrm{NIL}`$ 上停留一轮，下一轮才换到另一条的表头。

**理解过程**

这一步是不相交时让循环结束的关键。若 $`c = 0`$，两条链表没有公共结点，两个指针唯一可能相等的地方就是同时为 $`\mathrm{NIL}`$。正是 $`S_A`$、$`S_B`$ 中的 $`\mathrm{NIL}`$ 让引理 2 里的 $`T`$ 步恰好落在两个 $`\mathrm{NIL}`$ 上。变异检验中的第一种写法省掉了这一步，指针永远不为 $`\mathrm{NIL}`$，不相交时就死循环。相交时这一步也不多余：两个指针都多走了 1 步，仍然同时到达 $`C_0`$。

**可迁移思维：** 用“相等即停止”写循环时，要确认“没有答案”的情况也有一个双方都会到达的终点（这里是 `nil`），否则循环可能不终止。

### 难点三：换回自己的表头为什么也“能过”？

变异检验中，把 `a = headB` 改成 `a = headA`（`b` 同理）后，全部用例仍然通过。

**理解过程**

这样写时，`a` 以周期 $`m + 1`$ 在 $`A`$ 上绕圈，`b` 以周期 $`n + 1`$ 在 $`B`$ 上绕圈。按和定理相同的推理，私有结点永不相遇；若两者在 $`C_k`$ 或 $`\mathrm{NIL}`$ 相遇，往回退 $`k`$ 步（或 $`c`$ 步）两者都在 $`C_0`$，所以第一次相遇仍是正确答案。两者在第 $`\mathrm{lcm}(m + 1, n + 1) - 1`$ 步一定同时为 $`\mathrm{NIL}`$，所以循环总会结束。但相遇的步数可能达到 $`\mathrm{lcm}(m + 1, n + 1)`$ 量级：在 `max_length_unequal_no_intersection` 中，$`m + 1 = 30001`$ 与 $`n + 1 = 30000`$ 互素，要走约 $`9 \times 10^8`$ 步，在编写本题解的运行环境中这一个用例用了 1.66 秒，而正确写法只走 $`m + n + 1 \approx 6 \times 10^4`$ 步。测试只检查结果，所以抓不到它；区别在复杂度上。

**可迁移思维：** “结果对”不等于“算法对”。换到对方表头的意义在于把相遇步数控制在 $`m + n + 1`$ 以内；分析一个变体时，结果和复杂度要分开论证。

### 难点四：按结点比较，不按值比较

**理解过程**

示例 1 中，A 的第二个结点和 B 的第三个结点值都是 1，但它们是两个不同的结点，相交从值为 8 的结点才开始。Go 里 `a != b` 比较的是两个 `*ListNode` 指针是否指向同一个结点，正是题目要的“同一个结点”。引理 1 的“公共结点”也是这个意思：只有共用同一块内存，后面的结点才必然相同（关键条件 1）；值相同推不出这一点。

**可迁移思维：** 先分清题目要的是值相等还是引用相等。链表、树、图里“同一个结点”一般指引用相等。

## 6. 可迁移知识（Key Takeaways）

本题总结出以下可复用的方法：

1. **Shared Suffix Structure（公共尾部结构）**：在本题中，引理 1 证明两条无环单链表一旦相交，从相交点起直到表尾都相同，答案就是公共尾部的第一个结点。适用于所有“两条链在某处汇合”的问题，例如树上两个结点到根的路径。成立条件是每个结点只有一个后继；若结点有多个后继（一般的图），汇合后可以再分开，结论不成立。
2. **Length Equalization by Concatenation（拼接对齐长度）**：在本题中，两个指针分别走“A 再 B”和“B 再 A”，总长度相同，不用先求长度就能对齐。适用于需要让两个长度不同的序列同步到达某个位置的问题。需要有一个明确的“切换点”（这里是 `nil`），否则没有公共结点时循环不会结束。
3. **Two Pointers on Linked Lists（链表上的双指针）**：在本题中，两个指针同步前进，用 $`\Theta(1)`$ 额外空间代替记录已访问结点的散列集合。适用于找中点、倒数第 $`k`$ 个结点、判环等问题。限制：它依赖链表的特殊结构（这里是公共尾部），不是通用的集合求交方法。
4. **Reference Equality（引用相等）**：在本题中，`a != b` 比较的是结点地址，不是结点值。适用于链表、树、图上判断“是不是同一个结点”。值可以重复时，按值比较会给出错误答案。

用散列集合记录 A 的全部结点、再遍历 B 找第一个出现在集合中的结点，也是期望 $`O(m + n)`$ 时间的正确做法，但需要 $`\Theta(m)`$ 额外空间，不满足进阶要求。

---

**一句话总结**

两条无环单链表相交后一直共用到表尾，让两个指针各走“自己的链表 + `nil` + 对方的链表”，总长度相同，第一次相遇就是相交起点，不相交时则同时到达 `nil`。
